该模块为扁平的脚本目录，按用途自然划分为若干子域：
- `scripts/*.mjs`：基于 ES Modules 的 Node.js 工具脚本，通过 `#!/usr/bin/env node` 直接执行；其中 `build-connector-endpoints.mjs` 将 MCP 插件数据集合并为 Cloudflare Workers 可消费的 JSON，`verify-cloudflare-*.mjs` 系列是对各 Worker 子应用（http/chat/data/research）的健康检查与配置验证，`sync-vercel-env.mjs`、`reconcile-vercel-env.mjs`、`audit-public-env.mjs` 等围绕 Vercel CLI 进行 `.env.local` 与环境变量管理。
- `scripts/deploy-cloudflare-workers.sh` 与 `scripts/ops/*`：Bash 编排脚本，统一处理 `CLOUDFLARE_API_TOKEN` / `Cloudflare_Token` 别名、wrangler OAuth 回退、账户 ID 注入，并调用 `apply-cloudflare-challenge-policy.mjs`、`smoke-perf-stack.sh` 等完成策略下发与性能冒烟测试。
- `scripts/website/generate-pages-manifest.py`、`scripts/build_plugin_details_dataset.py`、`scripts/download_and_bundle_icons.py`：Python 脚本用于生成页面清单、插件详情数据集与图标打包。
- `scripts/claude_site_mirror/`、`scripts/cursor-marketplace/`：独立的 Python 爬虫子项目，分别镜像 claude.com 与 fetch Cursor Marketplace 数据，自带 `requirements.txt` 与 `run.sh`。
依赖方向单向：脚本读取仓库根下的 `public/data/`、`src/server/`、`src/client/` 等资源，不反向被业务代码引用，仅由 CI、本地开发或运维流程调用。
