- Cloudflare Workers 部署：`bash scripts/deploy-cloudflare-workers.sh`，支持 `CLOUDFLARE_API_TOKEN` 或 `Cloudflare_Token`（Cursor 环境密钥别名），未设置时回退到 `npx wrangler login` OAuth 会话。
- Vercel 环境变量同步：`npm run vercel:env:sync`（内部调用 `scripts/sync-vercel-env.mjs`），要求已 `npx vercel login` 或提供 `VERCEL_TOKEN`。
- Claude 站点镜像：进入 `scripts/claude_site_mirror/` 后 `pip install -r requirements.txt && ./run.sh`。
