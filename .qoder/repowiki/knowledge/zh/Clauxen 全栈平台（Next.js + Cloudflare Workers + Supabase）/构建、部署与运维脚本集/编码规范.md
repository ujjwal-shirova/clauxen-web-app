- Node.js 脚本统一使用 ES Modules 并以 `#!/usr/bin/env node` 作为 shebang，路径解析通过 `path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..")` 获取仓库根目录。
- 外部凭据通过环境变量注入，并对 Cursor 提供的 CamelCase 密钥名（如 `Cloudflare_Token`、`Vercel_Token`、`Supabase_Token`）做兼容别名映射后再赋值给大写版本。
- Cloudflare Workers 验证类脚本以 `[path, expectedStatus, method]` 元组数组声明断言用例，再通过 `Promise.all` 并发 `fetch` 请求并汇总结果。
- 需要 Vercel CLI 的脚本通过固定版本的 `npx vercel@41.7.0` 调用，避免不同环境下的版本漂移。
