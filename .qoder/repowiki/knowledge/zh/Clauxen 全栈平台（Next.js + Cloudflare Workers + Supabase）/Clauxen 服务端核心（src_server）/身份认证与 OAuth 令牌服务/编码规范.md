- 所有不透明令牌统一使用前缀 + base64url 随机字节生成（`generateOpaqueToken`），并通过 `hashToken(SHA-256)` 后写入数据库，避免明文存储。
- 对外错误通过继承 `AppError` 的子类（如 `OauthError`）并以 `(message, status, code)` 三元组构造，便于上层统一分类处理。
- 敏感或高频查询结果采用进程内 `Map` 缓存（token claims、用户活跃状态），并按时间戳与最大容量策略清理，避免跨请求泄漏。
- OAuth 流程中涉及比较的操作（PKCE challenge、hex token）一律使用 `timingSafeEqual` 进行常量时间比较。
- 数据库访问统一走 `query` / `queryOne` 参数化查询，SQL 模板中使用 `$1..$N` 占位符而非字符串拼接。
