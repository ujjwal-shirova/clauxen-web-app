- API 路由一律通过 `withApiHandler` 或更高层的 `withApiRoute` / `withApiRouteParams` 包裹，避免在路由文件中直接写鉴权、日志与异常处理。
- 可选鉴权通过 `withApiHandler` 的 `{ requireAuth, requireChatAuth }` 选项声明，失败时抛出 `unauthorized`，由外层统一转为 JSON 错误响应。
- 所有对外响应使用 `jsonData` / `jsonError` 构造，禁止直接返回裸字符串或对象，以保证生产环境隐藏内部错误信息。
- 环境变量统一经 `optional` / `firstOptional` 读取并提供默认值，敏感键优先走 Vercel Secrets 别名（如 `PROVIDER.apiKey`）再回退到明文变量。
- Cookie 写入通过 `applyConsentCookies` / `applyVisitorCookie` 等专用函数完成，并由 `cookieBase` 统一计算 `secure` / `sameSite` / `path`。
