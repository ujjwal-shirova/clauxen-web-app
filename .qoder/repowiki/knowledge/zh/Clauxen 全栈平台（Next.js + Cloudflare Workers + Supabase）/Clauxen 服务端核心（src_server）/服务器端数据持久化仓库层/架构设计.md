本模块是 server 层的纯数据访问层，每个文件对应一个领域表/聚合根，统一通过 `@/server/db/pool` 暴露的 `query` / `queryOne` 执行原生 SQL，所有表名均以 `public.` 前缀限定。仓库之间保持单向依赖：仅 `generation-jobs.repository.ts` 反向引用 `messages.repository.ts` 中的 `TurnFork` 类型，其他仓库彼此独立；对外仅导出函数与 TS 类型（如 `ChatRow`、`GenerationJobInput`、`ProfileRow`），不持有连接池实例，也不引入上层业务逻辑。复杂查询（分页、模糊搜索、JSONB 操作、SQL 函数调用如 `chat_id_exists`）以模板字符串内联在仓库函数中，配合 `AppError` 从 `@/server/db/errors` 透传数据库错误码（如 conflict）。
