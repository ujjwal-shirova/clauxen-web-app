模块按职责拆分为多个独立文件，共同构成聊天后端的业务层：
- 分布式执行编排：`durable-generation.ts` 通过 `generation-jobs.repository` 把模型流切分成有界 slice（SLICE_SOFT/HARD_MS、SLICE_MAX=48），配合 `chat-coord-client.ts` 调用外部 chat-coord Worker 做全局 lease/heartbeat/renew/release，实现跨实例抢占与崩溃恢复；`enqueue-chat-job.ts` 将标题生成、历史预热、嵌入写入、流式清理等任务投递到 pgmq。
- 深度研究与报告：`research.ts` 将 deep-research plan 转化为聊天作业并调度至 CF Queue，`research-report.ts` 负责报告聚合输出。
- 分享与存档：`share-token.ts` 用 AES-256-GCM + sha256 派生密钥对分享 token 进行加密封装；`share-snapshot.ts`、`chat-archive.ts`、`share-worker-client.ts` 协同 share-worker 完成快照归档与访问校验。
- 历史与元数据：`warm-history-cache.ts` 优先走 `/internal/enqueue` 异步预热，回退同步 `/internal/warm`；`recent-messages.ts`、`chat-document-metadata.ts`、`load-chat-route-seed.ts` 提供最近消息与文档种子读取。
- 安全：`turnstile.ts` 封装验证码校验。
依赖方向单向向下：本模块调用 `@/server/repositories/*`、`@/server/services/chat.service`、`@/server/db/pool` 和 Cloudflare serviceFetch，不被同级其他子目录反向引用。
