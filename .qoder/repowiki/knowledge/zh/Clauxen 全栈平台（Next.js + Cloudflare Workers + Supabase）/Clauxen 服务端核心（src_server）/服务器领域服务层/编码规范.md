- 服务函数以纯异步函数形式导出，参数包含 session/userId，返回值是结构化对象而非 HTTP 响应。
- 数据库访问统一通过 `@/server/db/pool` 的 `query` / `queryOne` 执行 SQL 模板字符串并传参数组，避免拼接。
- 仓库调用采用命名空间导入 `import * as xxxRepo from "@/server/repositories/xxx.repository"`，与服务内函数定义同文件组织。
- 用户身份校验通过 `requireSession(session)` 在入口处抛错，再向下传递已解构的 user.id。
- 错误处理使用 `AppError`（带 HTTP 状态码）或自定义 Error 并在 try/catch 中降级返回空结果（如 project-context）。
- 跨领域复用通过直接 import 另一个 service 的导出函数，而非在 route 层串联。
