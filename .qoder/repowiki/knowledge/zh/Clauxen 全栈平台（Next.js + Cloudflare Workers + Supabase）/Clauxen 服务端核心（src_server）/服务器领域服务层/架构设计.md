本模块是 server 侧的领域服务聚合目录，每个 `.service.ts` 对应一个业务域（chat、auth-credentials、billing、workspace、profile、files、library、scheduled-tasks 等），对外暴露函数式 API，内部通过 `@/server/repositories/*` 访问持久化数据。

- 依赖方向单向：services → repositories + 共享库（`@/app/api/chat/stream`、`@/lib/model-catalog`、`@/server/billing/*`、`@/server/inference/*`、`@/server/auth/*`），不反向引用 routes。
- 领域间复用通过直接 import 其他 service 实现（如 `scheduled-tasks.service.ts` 引用 `chat.service`）；跨领域基础设施则走 shared 包（db pool、config/env、auth/session、telemetry）。
- 特殊子职责：
  - `project-context.ts` 提供项目级 prompt 注入逻辑，被 chat 流程消费；
  - `personalization-style-instructions.ts` 集中风格指令常量供多服务复用；
  - `scheduled-tasks-schedule.ts` 与 `scheduled-tasks.service.ts` 分离调度算法与用例编排；
  - `auth-*` 系列按认证方式拆分（密码凭据、邮箱 OTP）。
