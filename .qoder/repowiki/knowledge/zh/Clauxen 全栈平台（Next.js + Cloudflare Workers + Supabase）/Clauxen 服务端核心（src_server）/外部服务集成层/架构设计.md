本模块按外部服务划分为若干平行的子目录（search/weather/github/assemblyai/dictation/email-verifier/training），每个目录仅暴露面向上层的函数与类型，不互相依赖。
- search：exa.ts 封装 Exa 语义搜索（支持 SSE 流式引用与 directResults 直查双路径），nominatim.ts 与 openverse.ts 分别对接 OpenStreetMap 与 Openverse 免费资源；均通过 `@/server/config/env` 读取密钥或走纯 fetch。
- weather/open-meteo.ts：无密钥的天气聚合 API，定义 GeocodedPlace / WeatherForecast 等结构化类型，并维护 WMO_CONDITION 代码表做条件映射。
- github/agent.ts：将 GitHub 操作转发到外部 claussen.com 内部 Agent，优先使用 Cloudflare Bindings 的 GITHUB_AGENT Fetcher，否则回退到全局 fetch，超时 90s。
- assemblyai/streaming-token.ts：封装 AssemblyAI 流式 token 兑换，内置 DICTATION_MAX_SESSION_SECONDS / INACTIVITY_TIMEOUT_SECONDS 硬上限并通过 AppError 抛出结构化错误码。
- dictation/types.ts + recording-store.ts：定义 DictationManifest、DictationChunk 等持久化结构，供语音录制会话状态管理。
- email-verifier/disposable-email.ts + .check.ts：内置一次性域名白名单，附带可独立运行的断言脚本。
- training/transcript-format.ts + transcript.schema.json：定义训练用转录数据的格式规范与 JSON Schema。

依赖方向单向向外：本模块只依赖 `@/server/config/env`、`@/server/db/errors`、`@/server/cloudflare/context` 等基础设施，不被其他 server 子模块反向引用。
