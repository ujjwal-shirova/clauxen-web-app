- 对外部 API 的错误通过 AppError 携带结构化 code（如 dictation_unavailable、dictation_token_failed）返回，而非直接抛原始 Error。
- 所有网络请求使用 AbortSignal.timeout() 设置硬性超时，避免上游挂起拖垮服务端。
- 可选凭据（API Key、token）集中从 `@/server/config/env` 的 requireXxxApiKey() 获取，未配置时立即抛出明确错误。
- 对第三方响应先定义内部 row 类型，再用 mapXxxResult 转换为本模块导出的稳定类型，屏蔽上游字段变更。
- 纯查询类函数在 HTTP 非 ok 时返回空结果（[] 或 null）而非抛错，由调用方决定是否重试。
