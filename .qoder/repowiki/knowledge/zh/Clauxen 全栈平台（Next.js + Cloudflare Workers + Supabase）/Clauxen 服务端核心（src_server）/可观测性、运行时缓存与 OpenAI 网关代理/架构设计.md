模块由四个互不依赖的子目录组成，各自承担单一横切职责：
- `observability/log.ts`：基于 `console.error/warn` 输出 JSON Lines，提供 `logError`、`logWarn` 与 `logged(scope)` 回调（用于 `.catch(logged(...))` 风格的后台错误捕获），通过 `scope` 字段供 Vercel 日志筛选。
- `cache/runtime-cache.ts`：封装 Cloudflare KV (`APP_CONFIG_KV`) 作为不可变运行时常量缓存，按 `settings:` 前缀禁止缓存可变用户设置；通过 `RUNTIME_CACHE_TAGS` 常量（`user-settings`、`model-catalog`）与 `invalidateRuntimeCacheTags` 配合 tag 失效策略，对外暴露 `cacheUserSettings/readCachedUserSettings` 与 `cacheModelCatalog/readCachedModelCatalog` 两对读写 API。
- `telemetry/inference-log.ts`：将推理请求指标写入 `public.inference_gateway_requests` 表，先通过 `isDatabaseConfigured()` 短路，所有异常被吞掉以保证“遥测不能中断聊天”。
- `shirova-openai.ts`：Next.js Route Handler，校验 `Authorization: Bearer` 或 `x-shirova-api-key` 头中的白名单 key，转发给 `openai` SDK 的 `responses.create`；流式响应以 SSE (`event: /data:`) 形式回写，非流式直接返回 JSON。
依赖方向单向向外：本模块被业务 handler 引用，自身仅依赖 `@/server/db/pool`、`@/server/config/env`、`@/server/cloudflare/context` 与第三方库。
