- 对外 HTTP 入口统一经 http/api-handler.ts 包装，内部错误映射为 api-response.ts 定义的响应结构
- 鉴权与会话解析在 http 中间件中完成，业务代码通过 require-session 或 JWT 校验获取用户上下文
- 数据库访问集中到 repositories/* 下的异步函数，业务逻辑不得直接拼接 SQL
- 外部第三方服务（Razorpay、OpenAI、Search、Weather、AssemblyAI 等）通过各自独立目录封装，对上层暴露简洁函数接口
- 可观测性通过 observability/log.ts 的结构化日志输出，推理遥测通过 telemetry/inference-log.ts 写入
