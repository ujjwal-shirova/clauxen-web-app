模块以 `index.ts` 作为对外唯一入口，仅重导出三类能力：(1) 运行期 `runAgent/runAutonomousAgent/generateChatTitle` 及其类型；(2) `productionDeps`/`QueryDeps` 依赖注入；(3) OpenAI provider 包装与工具编组。内部按职责分目录：
- `runtime/`：`query-loop.ts` 实现真正的自主代理轮次（最多 MAX_STEPS=24 步），处理 reasoning → narration → strict function calls → tool execution → next round 的状态机，并通过 `ClausenSseStream` 向客户端推送 flat trace。
- `provider/messages-client.ts`：对 `@/server/inference/openai-responses-client` 做薄封装，同时复用 `@/server/config/env` 中的 `requireOpenAIApiKey`/`optionalOpenAIBaseUrl`。
- `tools/index.ts`：将实际工具定义与执行器从 `@/server/inference/autonomous-tools` 再导出，使 agent loop 不直接感知具体工具实现。
- `query/deps.ts`：定义 `QueryDeps = { callModel, uuid }` 及 `productionDeps()`，便于在测试中替换模型调用与 UUID 生成。
- `sdk-tools.d.ts`：由 json-schema-to-typescript 自动生成的工具输入输出 TypeScript 类型，禁止手工修改。

依赖方向单向：`runtime/query-loop` → `provider/messages-client` + `tools` + `query/deps`；`provider` 与 `tools` 不反向引用 `runtime`。agent loop 还横向集成 `@/server/plugins/plugin-runtime`（MCP 工具）与 `@/server/inference/tool-healer`（参数自愈校验）。
