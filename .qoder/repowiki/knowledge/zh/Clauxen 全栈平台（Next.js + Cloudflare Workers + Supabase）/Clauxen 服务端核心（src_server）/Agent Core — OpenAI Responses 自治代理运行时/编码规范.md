- 对外 API 通过 `src/server/agent-core/index.ts` 单一入口集中 re-export，子目录不直接向业务路由暴露内部实现。
- 可插拔外部依赖（模型调用、UUID 生成）通过 `QueryDeps` 接口 + `productionDeps()` 工厂注入，而非直接 import 实例。
- 工具实现与工具注册解耦：具体工具放在 `@/server/inference/autonomous-tools`，agent-core 仅通过 `tools/index.ts` 重新导出 `autonomousAgentTools` 与 `executeAutonomousTool`。
- 所有工具输入参数使用 Zod schema 在 agent loop 侧进行二次校验（`autonomousZodByName`），结合 `tool-healer` 实现参数自愈。
- SDK 层类型（`sdk-tools.d.ts`）由 json-schema-to-typescript 自动维护，禁止手写修改。
