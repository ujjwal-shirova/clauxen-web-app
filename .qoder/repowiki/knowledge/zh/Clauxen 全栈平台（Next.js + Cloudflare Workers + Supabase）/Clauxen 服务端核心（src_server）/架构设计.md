src/server 采用分层 + 横向基础设施的架构：
- 横切基础设施层（infrastructure、http_framework、config、observability_and_misc）提供 Supabase/PostgreSQL 连接池、Cloudflare Worker 请求上下文、API 路由包装器、结构化日志与运行时常量缓存，被所有上层模块复用。
- 业务编排层（services）作为 API 路由与持久化之间的用例协调者，调用 repositories 访问 PostgreSQL，并组合 auth_identity、billing、chat、inference、plugins、integrations 等能力。
- 执行引擎层（agent_core、inference、sandbox_runtime、plugins）共同实现自治代理链：agent_core 驱动 OpenAI Responses 循环，inference 对接模型流式协议，sandbox_runtime 提供进程级隔离，plugins 暴露已授权第三方工具集并通过防火墙校验。
- 数据层（repositories）直接面向 PostgreSQL，按域拆分（chats、messages、billing、plugin-connections 等），由 services 统一封装。
- 外部集成（integrations）通过统一的客户端封装搜索、天气、GitHub、AssemblyAI 等第三方 API。
各子模块之间以 TypeScript 函数/类接口通信，无共享状态；跨子模块共享依赖集中在 infrastructure 与 http/framework 中。
