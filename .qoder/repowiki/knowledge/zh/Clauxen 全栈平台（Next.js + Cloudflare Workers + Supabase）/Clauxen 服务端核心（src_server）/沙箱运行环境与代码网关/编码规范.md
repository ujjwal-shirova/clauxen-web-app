- 对外返回的对象统一通过 `serializeInfo` 或类似函数裁剪为 `SandboxPublicInfo`，避免把内部元数据泄露给调用方。
- 对第三方 SDK（novita-sandbox、OpenAI）采用延迟 `import()` 加载，并把凭据通过 `process.env` 注入而非直接传参。
- 鉴权失败与越权访问统一返回 `NextResponse.json({ error: { type, message } })`，并按语义选择状态码（401/402/400/500）。
- 用户资源隔离通过 userId/conversationId 作为 session key，并在内存 Map 中缓存已连接沙箱以支持自动恢复。
