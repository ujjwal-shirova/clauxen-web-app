模块由两个子目录组成，职责清晰分离：
- `src/server/sandbox/`：沙箱运行时封装层。`types.ts` 定义创建选项、会话上下文与公开信息结构；`sandbox-manager.ts` 通过动态 `import('novita-sandbox/code-interpreter')` 懒加载 SDK，在进程内维护 `sessionIndex` / `codeContextIndex` 两张 Map 做按 userId+conversationId 键的沙箱复用，并提供 `createSandbox`、`connectSandbox`、`getOrCreateSandbox`、`listSandboxes`、`getSandboxInfo`、`assertSandboxOwnedBy` 等对外 API。所有调用前通过 `ensureProviderKey()` 将服务端配置的 NOVITA_API_KEY 注入 `process.env`，并统一用 `serializeInfo` 剥离内部字段只暴露 `SandboxPublicInfo`。
- `src/server/code-gateway/responses.ts`：Next.js Route Handler，实现 `/api/v1/code/v1/responses`，鉴权走 `getSessionFromRequest`，余额校验走 `getUserBalance`/`debitUserTokens`，上游统一转发到 OpenAI `client.responses.create`，并以 SSE (`text/event-stream`) 透传流式事件、非流模式返回 JSON，同时根据 usage 扣费。
依赖方向单向：gateway 不依赖 sandbox，sandbox 也不依赖 gateway，二者仅共享上层 Next.js 运行时。
