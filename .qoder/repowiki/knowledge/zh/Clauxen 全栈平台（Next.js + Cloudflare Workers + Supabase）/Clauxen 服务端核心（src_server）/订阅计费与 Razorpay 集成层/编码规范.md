- 对外部依赖（Razorpay、Cloudflare billing Worker、Razorpay Keys）通过 `is*Configured()` 守卫函数检查，缺失时抛出 `AppError(503, 'billing_unavailable')`，使未配置环境可优雅降级。
- 所有来自客户端的敏感字段（planId、billingCycle、currency、maxTier、seatBreakdown、organizationSeatCount、returnPath）均在服务端用 `assertCheckoutClaimsMatchClientInput` 或正则/白名单校验后使用，杜绝信任前端。
- 金额一律以整数 minor unit（paise/cents）传递与比较，仅在展示层除以 100 转为法币单位。
- HTTP 响应错误统一经由 `AppError` 携带语义化 code（如 `razorpay_error`、`invalid_session`、`invalid_seats`、`session_expired`），便于上层分类处理。
- 安全比较（签名、HMAC）使用 Node `crypto.timingSafeEqual`，避免时序攻击；签名结果采用 base64url 编码以适配 URL 场景。
