- 跨请求共享的昂贵资源（如 `pg.Pool`、Supabase Client）以模块级变量缓存并在首次使用时惰性创建，避免每次请求重复初始化。
- Cloudflare Worker 中的临时资源通过 `withRequestResources` + `requestResource` 注册，利用 `AsyncLocalStorage` 保证仅在当前 invocation 内复用并在结束时统一 dispose。
- 数据库错误统一经 `mapPgError` 转换后抛出 `AppError`，根据 PostgreSQL error code（P0001、23505、23503、53300 等）映射到语义化状态码与 code 字段，而非直接暴露底层错误。
- 环境变量读取集中在 `lib/vercel-env` 提供的 `resolve*` 辅助函数中，由 `getSupabaseAdmin` 等入口显式检查缺失并抛出带人类可读信息的错误。
