模块以 `definitions.ts` 暴露 `AutonomousAgentTool[]`（OpenAI function-calling schema），作为模型选择工具的声明层；`executor.ts` 是唯一的执行入口 `executeAutonomousTool(name, args, ctx)`，按名称分派到各子能力：GitHub 操作、Web/Places/Image/Weather 搜索、代码执行、沙箱文件读写、技能查询等，并通过动态 `import()` 延迟加载外部依赖以降低冷启动成本。

- `workspace.ts` 封装基于 `sandbox-manager` 的会话级隔离文件系统，提供 `ensureSandboxWorkspace`、`resolveSandboxWorkspacePath`、`readScopedFile`/`writeScopedFile` 等 API，将模型传入路径映射到 `/workspace/clauxen/<conversationId>` 并限制绝对路径写入到 `outputs/`。
- `skill-catalog.ts` 从内嵌的 `skills-pack/` 及可选 `CLAUXEN_SKILLS_DIRS` 环境变量扫描 `SKILL.md` 构建技能清单，供 `read_skill` 工具使用。
- `persist-agent-file.ts` 把 Agent 产出的工件持久化到 R2 + Supabase `user_files`，附带 MIME 推断与元数据。
- `read-attachment.ts` 从对象存储拉取用户上传附件，按图片/文本/二进制三种 kind 返回给模型。

依赖方向单向向外：本模块仅消费 `@/server/sandbox/*`、`@/server/search/*`、`@/server/storage/*`、`@/server/repositories/*` 等上层服务，不反向被它们引用。
