- 工具通过 `definitions.ts` 中的 `AutonomousAgentTool` 数组声明 JSON Schema，并在 `executor.ts` 中以字符串名称进行分支分派，schema 与实现解耦。
- 对外部重型依赖（如 GitHub agent、persist-agent-file）采用函数体内 `await import()` 动态导入，避免主包冷启动开销。
- 所有面向模型的描述性字段使用自然语言编写，包含 WHEN/WHAT/HOW 提示、主动调用建议、序列编排提示与禁止用法，作为对模型的“思维引导”。
- 沙箱路径统一通过 `resolveSandboxWorkspacePath` / `resolveSandboxReadableCandidates` 归一化，模型提供的绝对路径被重定向到 `outputs/` 子目录，防止逃逸。
- 异步 I/O 错误采用 try/catch 累加 lastError 后抛出，保持失败信息一致。
