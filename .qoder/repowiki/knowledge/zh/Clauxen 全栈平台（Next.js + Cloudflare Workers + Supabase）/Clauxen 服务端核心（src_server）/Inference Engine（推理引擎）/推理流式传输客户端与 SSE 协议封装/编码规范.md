- SSE 事件以固定 JSON 结构通过 `data: {"type":...}` 行发送，事件类型由 `type` 字段区分（start、segment_start/end、thinking_*、narration_delta、answer_*、tool_*、artifact_upsert、chat_title、error、done）。
- 对可选字段的 delta/segmentId 等参数采用 `typeof x === 'string'` 守卫后再传给回调，避免上游传入的未知字段污染持久化逻辑。
- 长连接通过 AbortSignal + idleTimeout 双重保活：OpenAI 侧用 `createProviderActivityGuard` 检测空闲并中断，SSE 侧在 `signal.addEventListener('abort')` 上取消 reader。
- 生产端在控制器尚未 attach 时将事件写入 `pending: Uint8Array[]` 队列，消费者 attach 后一次性 flush，保证 early frames 不丢。
