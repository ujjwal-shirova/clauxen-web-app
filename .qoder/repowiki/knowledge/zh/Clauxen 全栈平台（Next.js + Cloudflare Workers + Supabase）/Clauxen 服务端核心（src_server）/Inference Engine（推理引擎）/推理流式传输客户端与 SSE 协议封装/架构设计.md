模块由三个文件组成两层职责：
- 底层适配器 `openai-responses-client.ts`：基于 `openai` SDK 发起 Chat Completions 流式请求，通过 `providerThinkingControls` 注入 reasoning/thinking 控制参数，使用 `createProviderActivityGuard` 实现 idle timeout 与 abort 信号传播；将 OpenAI chunk 归一化为 `OpenAIStreamPart`（reasoning-delta / text-delta / tool-call-* / finish / error / abort），并以 AsyncGenerator 形式向上游暴露。
- 上层协议层 `clauxen-sse-stream.ts`：定义 `ClauxenSseStream` 类，将 StreamEvent 序列化为 `text/event-stream`（`data: {...}\n\n`），对外提供 `writeStart/writeThinking*/*writeNarrationDelta/writeTool*/*writeArtifact` 等强类型写入方法；内部用 `ReadableStream` + pending 缓冲在消费者 attach controller 之前暂存帧，避免早期 start/tool 帧丢失。
- 旁路解析器 `clauxen-ui-stream.ts`：提供 `tapUiMessageSseStream` 函数，以只读方式消费上游 SSE 字节流，按 `type` 字段分发到 onAnswer/onThinking/onSegment/onNarration/onTool/onError 等回调，用于 DB 持久化与 UI 追踪。
依赖方向单向：`openai-responses-client.ts` → `provider-thinking`/`provider-activity`；`clauxen-sse-stream.ts` 与 `clauxen-ui-stream.ts` 共享同一套 SSE JSON Schema（`StreamEvent` from `@/lib/chat-stream`），分别承担“生产者”和“旁路消费者”角色。
