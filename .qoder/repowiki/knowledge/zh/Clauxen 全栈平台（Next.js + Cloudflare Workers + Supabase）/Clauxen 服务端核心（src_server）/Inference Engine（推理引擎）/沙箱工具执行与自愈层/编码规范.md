- 对外暴露能力以纯函数 + 类型别名为主（如 `healToolArgs`、`executeToolSafely`、`ToolDefinition`、`ToolExecutionContext`），避免类或隐式状态。
- 输入校验采用「try → heal → fallback」三段式：先用 Zod `safeParse` 验证，失败后应用确定性启发式修复，最终仍失败则返回 null 或带 error 的结果对象，而不是向上抛错。
- 危险操作前置断言：Bash 命令在执行前通过 `assertSafeBashCommand` 进行空串、长度与黑名单正则三重检查，任何一条命中即抛 Error。
