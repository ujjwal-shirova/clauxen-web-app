本模块由三个职责正交的文件组成，统一面向 inference 上层：
- `sandbox-session.ts` 是薄转发层，仅从 `@/server/sandbox/sandbox-manager` 重新导出沙箱生命周期与文件操作 API（如 `getOrCreateSandbox`、`runSandboxCommand`、`writeSandboxFiles`），并保留已弃用的 `ensureSandboxReady` 作为向后兼容入口。
- `bash-safety.ts` 定义 Bash 命令白名单策略：常量 `MAX_BASH_COMMAND_CHARS` 限制长度，正则数组 `BLOCKED_BASH_PATTERNS`（如 `rm -rf /`、`chmod -R 777 /`、curl/wget | sh）匹配危险命令，并由 `assertSafeBashCommand` 在运行前抛出异常阻断。
- `tool-healer.ts` 实现「免疫式」工具调用包装：通过 `healToolArgs` 对 LLM 传入的畸形参数进行三步自愈——先 Zod 校验，再 `applyHeuristics`（字符串转数字/布尔、单元素数组解包、`{value}` 展开），最后 `coerceToSchema` 按 schema 字段类型强制转换；配合 `executeToolSafely` 对外暴露 `ToolDefinition`（含 name/description/inputSchema/execute）与 `ToolExecutionContext`（携带 conversationId、modelId、onProgress 等追踪元数据）接口，失败时返回结构化 error 而非抛错。
依赖方向单向向外：本模块被 inference executor 引用，不反向依赖更高层业务逻辑。
