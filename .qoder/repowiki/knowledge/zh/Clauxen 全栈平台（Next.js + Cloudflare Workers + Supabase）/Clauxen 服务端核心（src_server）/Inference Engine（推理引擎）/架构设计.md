本模块以 `agent-engine.ts` 为入口编排三个子层：
- 提示与模型层：`system-prompt.ts`、`model-prompts.ts`、`build-chat-prompt-messages.ts`、`language.ts`、`research-evidence.ts`、`vision-attachments.ts` 负责拼装系统提示、多模态附件与研究证据；`openai-responses-client.ts`、`novita.ts`、`provider-thinking.ts`、`provider-activity.ts` 封装不同推理提供商。
- 流式传输层：`clauxen-sse-stream.ts`、`clauxen-ui-stream.ts` 把上游调用统一转为 Clauxen SSE 事件（thinking/narration/tool/artifact），由上层 agent 循环消费。
- 工具执行层：`autonomous-tools/` 提供工具定义、技能目录与沙箱工作区；`sandbox-session.ts`、`bash-safety.ts`、`tool-healer.ts` 提供安全 Bash 守卫与 Zod schema 自愈执行。
三者通过共享的 Clauxen SSE 协议与沙箱工作区 API 解耦：提示层产出消息，流式层转发给下游，工具层在独立沙箱中执行业务能力，彼此不直接耦合。
