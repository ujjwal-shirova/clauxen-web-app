- 工具名称统一使用 `mcp__<slugFor(pluginId)>__<sanitizedToolName>` 前缀并在 64 字符内截断，slug 仅保留 a-z0-9 下划线。
- 对 provider 的 OAuth 行为差异（client_id、scope separator、resource indicator、identity scopes）通过 `OAuthProviderConfig` 对象集中声明，而非散落在调用处。
- 对外暴露的敏感数据一律先经 `sanitizeUntrustedOutput` 清洗并附加 `UNTRUSTED_CONTENT_NOTICE`，模型永远不直接拿到原始 access token。
- 工具风险等级采用 `read | write | destructive` 三态枚举，权限判断通过 `allowedByMode(connection.permission_mode, risk_level)` 判定。
- 未配置凭证的 provider 通过 `providerCredentials(id)` 返回 null 的方式被上游拒绝，而不是抛出异常或硬编码默认值。
