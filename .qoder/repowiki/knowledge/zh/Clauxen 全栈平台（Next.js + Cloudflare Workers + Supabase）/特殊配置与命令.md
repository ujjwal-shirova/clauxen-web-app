根级 `npm run dev` 启动 Next.js 开发服务器（端口 9002），`npm run build` 会先执行 `scripts/bundle-server-text.mjs` 与 `bundle-research-exports.mjs` 再走 `next build`；Cloudflare Workers 侧通过 `npm run cf:build` / `cf:deploy` / `cf:preview` / `cf:release` 由 `scripts/cloudflare-run.mjs` 包装 OpenNextJS 构建流程；`npm run supabase:db:push` 推送 SQL 迁移；`npm run plugins:endpoints` 生成连接器端点。
