- 前后端共享类型与校验统一放在 `src/shared`，通过 Zod schema 描述 API 契约并在前端与服务端同时使用
- 所有 Node 脚本位于 `scripts/`，由根 `package.json` 的 npm scripts 统一调用，避免分散的 bin 入口
- 环境变量与 Secret 通过 Vercel 面板与 `scripts/sync-vercel-env-api.mjs` 同步，Worker 侧通过 wrangler.toml 声明
- 数据库变更以 `supabase/migrations` 中的带时间戳 SQL 文件提交，并由 CI 通过 `supabase db push` 验证
