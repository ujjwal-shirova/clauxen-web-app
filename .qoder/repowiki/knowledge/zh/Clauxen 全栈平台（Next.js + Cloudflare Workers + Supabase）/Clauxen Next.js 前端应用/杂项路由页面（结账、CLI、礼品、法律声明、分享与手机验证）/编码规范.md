- 页面组件作为服务端壳：解构 Next.js 传入的 `params` / `searchParams`，再将原始值透传给对应的 `*Client` 组件完成渲染。
- 需要鉴权的页面在获取用户前先检查登录态，未登录时通过 `redirect('/login?redirectTo=...')` 保留当前路径查询参数。
- 对外部异步 UI 用 `<Suspense fallback={<AuthLoadingShell />}>(...) </Suspense>` 包裹，保证加载状态一致。
- 面向 SEO 的静态页面通过导出 `metadata: { title: '...' }` 设置页面标题。
- URL 参数类型通过本地 `interface` / `type PageProps = { params: Promise<{ ... }> }` 声明，而非使用泛型。
