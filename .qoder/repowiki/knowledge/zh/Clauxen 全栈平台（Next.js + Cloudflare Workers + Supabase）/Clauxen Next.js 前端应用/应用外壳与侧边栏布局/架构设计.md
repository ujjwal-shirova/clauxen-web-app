本模块由三个协作的 React 客户端组件构成：
- `main-layout.tsx` 是应用根布局（`MainLayoutShell`），通过 `AppLayoutProvider`、`ChatSessionProvider`、`AppOverlaysProvider` 等上下文 Provider 包裹子路由，并集中处理认证门控（`useAuthGate`）、访客重定向到 `/new`、未登录时保留 App Shell 而非跳转登录页、移动端全屏前缀匹配、侧边栏 peek 交互以及预取常用路由。
- `sidebar.tsx` 实现完整的侧边栏 UI，包含聊天分组、固定/最近会话列表、搜索、项目创建、设置下拉菜单、用户头像及 Pin Tip 浮层；状态通过 `localStorage` 持久化（`clauxen_chat_group_by`、`clauxen_sidebar_section_*`、`clauxen_sidebar_pin_tip_dismissed`）。
- `app-route-loading-shell.tsx` 提供轻量级骨架屏（`AppRouteLoadingShell`），复用 `Skeleton` 组件渲染占位内容。
依赖方向单向向外：布局 → 侧边栏 → 各业务对话框/图标/UI 组件；布局与侧边栏共享 `useSidebarState`、`APP_ROUTES`、`useAppPathname` 等横切能力，不反向依赖业务页面。
