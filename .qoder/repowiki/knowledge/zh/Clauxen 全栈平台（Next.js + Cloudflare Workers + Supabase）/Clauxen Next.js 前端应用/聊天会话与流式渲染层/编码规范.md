- 长串文本流式更新统一经过 `useSmoothStreamingText` 包裹，并通过 `streamKey` 稳定 key 避免频繁 remount。
- Markdown 内容在交给渲染器前一律走 `normalizeLatexDelimiters` + `prepareFollowUpContent` + 引用剥离/转换管线，确保 LaTeX 与 follow-up `<prompt>` 标签被正确提取。
- 可复用的 SVG 图标以内联函数组件形式就近定义（如 `RetryIcon`、`ShareIcon`、`ThumbsUpIcon`），而非引入外部 icon 包。

- 响应式布局通过 `useIsMobile()` hook 与 Tailwind 类名共同控制，桌面端固定像素宽度的 rail（`ARTIFACT_VIEWER_MIN/MAX/DEFAULT`、`SOURCES_PANEL_WIDTH`）保持布局稳定。
