本模块由三个相邻的 React Server/Client 组件组成，职责逐层收敛：
- `chat-area.tsx` 作为会话装配器（`ChatAreaLayout`），通过 `ArtifactViewerProvider`、`useArtifactViewer` 等上下文协调 `ResearchSidebarLayout`、`IsolatedChatInput`、`ChatViewPane`、`ChatSourcesPanel`、`ArtifactLibrary` 等子面板，并依据 hydrating / creating / incognito / mobile 等状态切换骨架屏、空白面板或完整对话 UI。
- `conversation-thread.tsx` 是消息列表渲染层，把扁平 `Message[]` 通过 `groupMessagesIntoTurns` 分组为 `ConversationTurnGroup`，按分支（prev/next）导航、重试、编辑、点赞/点踩、来源面板入口、快速滚动禁用交互等行为组织每轮消息；使用 `createPortal` 将浮层（如编辑气泡）挂载到文档根节点。
- `streaming-markdown.tsx` 提供流式 Markdown 渲染：先经 `useSmoothStreamingText` 平滑 token 拼接，再走 `normalizeLatexDelimiters → stripReferenceDefinitions → prepareFollowUpContent → convertCitationReferencesToLinks` 管线，最终交由 `StreamdownStreamingMarkdown` 增量解析，并在非 streaming 状态下渲染 Follow-up 提示行。
依赖方向单向向下：三者均消费 `@/lib/chat-sources`、`@/lib/types`、`@/contexts/*` 等共享库，不反向被业务逻辑引用，仅被更高层 shell/路由容器组合。
