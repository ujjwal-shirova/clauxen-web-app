- 认证相关组件统一使用 `"use client"` 指令并以函数式组件 + 具名导出方式暴露。
- 全局视觉风格通过 `authPageStyles` 对象集中定义（按钮、输入框、文本链接等），子组件通过 `cn(authPageStyles.xxx, ...)` 组合 Tailwind 类。
- 异步表单提交流程采用 try/catch/finally 结构：提交前清空 error 并设置 submitting，catch 中归一化为字符串错误消息，finally 重置 loading。
- 外部第三方库（如 Google GSI）通过 `useEffect` 内联加载，使用 `data-clx-*` 属性标记已注入元素以避免重复挂载，并在卸载回调中清理事件监听与定时器。
- 错误信息展示统一通过 `role="alert"` 的段落或 shadcn/ui Alert 呈现，颜色区分 error/info 两类。
