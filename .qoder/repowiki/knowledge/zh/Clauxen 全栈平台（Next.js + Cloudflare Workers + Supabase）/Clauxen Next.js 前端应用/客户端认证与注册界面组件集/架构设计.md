该模块以 React 客户端组件形式组织，围绕 `useAuth` hook（来自 `@/hooks/use-auth`）和 Supabase Auth SDK 构建认证流程：
- 入口/布局层：`auth-shell.tsx` 提供单列居中的认证页面外壳；`auth-dialog.tsx` 基于 shadcn/ui `Dialog` 实现登录/注册双模式弹窗。
- 表单与校验层：`auth-gate-dialog.tsx`、`auth-gate-form.tsx` 组合为受 Gate 上下文保护的认证表单；`signup-otp-dialog.tsx` 复用 `InputOTP` 组件完成注册后邮箱验证码输入。
- OAuth 集成层：`google-one-tap.tsx` 动态注入 Google Identity Services 脚本并调用 `signInWithIdToken`，通过 `crypto.subtle.digest` 生成 FedCM nonce，同时监听 `auth-gate-context` 避免与内嵌弹窗竞争。
- 共享资源层：`auth-shared.tsx` 集中导出认证页样式 token（`authPageStyles`）、OAuth 提供商图标（Google/GitHub/GitLab/X/Apple）、`ProviderMark`、`AuthSpinner`、`looksLikeEmail/Phone` 等工具类型及重定向辅助函数；`clauxen-wordmark.tsx` 提供品牌 Logo。
依赖方向单向向外：本模块仅消费 `@/hooks/use-auth`、`@/contexts/auth-gate-context`、`@/utils/supabase/client` 与 shadcn/ui 原子组件，不暴露内部状态给父组件，所有交互通过 props 回调向上冒泡。
