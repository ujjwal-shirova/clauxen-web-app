- 基于 Next.js App Router 的 `(marketing)` 路由组，`layout.tsx` 作为所有公共营销页面的共享外壳，仅渲染 `marketing.module.css` 中的 `.shell` 容器并设置全局 metadata（title/description）。
- 页面按主题分目录组织：`overview/` 为首页；`features/[slug]/`、`use-cases/[slug]/`、`apps/[slug]/` 为参数化内容页；`plans/`、`plans/[plan]/` 为定价页；`business/{education,enterprise}/` 为企业/教育落地页；`download/` 为下载入口。
- `_components/` 内复用三个轻量 UI 片段：`MarketingPlaceholder` + `marketingPlaceholderMetadata` 工厂用于快速生成 SEO metadata 和占位页面结构（如 plans/page.tsx），`OverviewModes` 展示能力模式切换，`ScreenshotPlaceholder` 渲染产品截图占位。
- 样式全部通过 CSS Modules（`marketing.module.css`）隔离，页面组件直接 import `../marketing.module.css`，避免跨页面样式泄漏。
- 依赖方向单向向下：页面 → `_components` 内部组件 → CSS Modules，不引用应用内其他业务模块，保持营销站点的纯静态展示属性。
