- 每个页面文件通过导出 `metadata: Metadata` 对象声明 SEO 信息，并在 `alternates.canonical` 中指定规范 URL。
- 面向快速搭建的内容页使用 `_components/marketing-placeholder.tsx` 提供的 `MarketingPlaceholder` 组件与 `marketingPlaceholderMetadata` 工厂函数统一生成标题、描述与占位布局。
- 页面级样式统一从同级或父级的 `marketing.module.css` 以 CSS Modules 形式导入，类名使用 kebab-case 且通过 `styles.xxx` 引用。
