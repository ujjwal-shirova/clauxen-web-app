- 所有 route handler 统一使用 `withApiHandler` 高阶函数包裹异步处理器，并以 `jsonData` 构造成功响应体。
- 每个 route 文件显式导出 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`，表明这些端点需要 Node 运行时能力。
- 输入校验失败时抛出 `AppError`（来自 `@/server/db/errors`），携带人类可读 message、HTTP 状态码及语义化 code（如 `invalid_email`、`rate_limited`、`account_deleted`）。
- 用户会话通过 `sessionCookieHeader` / `clearSessionCookieHeader` 设置 httpOnly cookie，并通过 `IDENTITY_HINT_COOKIE` 辅助 cookie 同步前端渲染所需的最小身份信息。
- 邮箱地址在关键路径上统一经 `assertEmailNotDisposable` 拦截一次性邮箱，并在登录后记录 `logSecurityEvent` 安全审计事件。
