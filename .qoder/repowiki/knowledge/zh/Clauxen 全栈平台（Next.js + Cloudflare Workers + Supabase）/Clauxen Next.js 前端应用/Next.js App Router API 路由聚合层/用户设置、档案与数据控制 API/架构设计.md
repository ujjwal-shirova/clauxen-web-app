本模块由一组 Next.js App Router 风格的 `route.ts` 文件组成，按 URL 空间划分为三个并列子域：
- `profile/route.ts`：GET/PATCH 当前用户的个人资料（邮箱、显示名、头像、可见性开关）。
- `my-clauxen/route.ts`：GET/PATCH MyClauxen 功能开关。
- `settings/`：聚合型入口 `route.ts` 负责设置项的默认值合并、校验与缓存失效；子目录 `data-deletion`、`data-export`、`security` 分别处理数据删除请求、异步导出任务查询/创建与安全性设置读取。

所有路由统一通过 `withApiHandler` 高阶函数包裹，并在 handler 内部调用 `requireSession` 从 session 中解出当前用户，随后委托给 `@/server/services/*` 层的服务函数，服务再调用 repositories 和数据库池。响应一律经 `jsonData` 序列化。每个路由都声明 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`，表明这些端点依赖运行时会话与可变状态，不能静态生成。设置端点还通过 `cacheUserSettings` / `invalidateUserSettingsCache` 对 Redis 级用户设置缓存做读写协同。
