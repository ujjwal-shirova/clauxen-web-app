- 每个 route.ts 以 `export const runtime = "nodejs"` 与 `export const dynamic = "force-dynamic"` 开头，显式声明动态 Node.js 执行环境。
- HTTP 处理器统一使用 `withApiHandler(async ({ session, request }) => {...}, { requireAuth: true })` 包裹，handler 内通过 `requireSession(session)` 提取用户上下文。
- 响应体一律经 `jsonData(payload, status?)` 返回，错误则抛出 `AppError` 并附带 HTTP 状态码与错误码。
- 业务逻辑不直接写 SQL，而是委派给 `@/server/services/*` 命名下的服务模块，路由仅承担参数解析与响应封装职责。
- 入参校验采用轻量 inline 类型守卫 + `AppError` 抛错的模式（如字段类型检查、枚举白名单），不在路由层引入外部 schema 库。
