- 每个 HTTP 端点以 `route.ts` 文件实现，REST 动词由同名函数导出（GET/POST/PUT/DELETE），URL 段通过 `[param]` 动态路由捕获
- 对外公开 API 统一放在 `/api/v1/...`，仅内部使用的端点放入 `/api/internal/...` 以示隔离
- 需要鉴权的端点在 handler 内通过 session/token 校验后再调用下游服务，错误以统一的 NextResponse 返回
- 外部支付与插件回调类端点放在独立的 webhook 子目录（如 `webhooks/razorpay`、`plugins/callback`），命名体现回调来源
