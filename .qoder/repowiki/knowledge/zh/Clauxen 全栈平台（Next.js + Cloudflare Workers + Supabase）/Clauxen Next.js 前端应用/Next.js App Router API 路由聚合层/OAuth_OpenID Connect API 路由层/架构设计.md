每个子目录对应一个 OAuth 端点（authorize、token、device/code、device/approve、revoke、userinfo、hello），均通过 Next.js App Router 的 `route.ts` 暴露 POST/GET 处理器。

- 表现层：所有路由统一声明 `runtime = 'nodejs'` 与 `dynamic = 'force-dynamic'`，仅做请求解析、鉴权调用与错误包装，无业务逻辑。
- 服务层：所有 OAuth 核心流程委托给 `@/server/oauth/service`（如 `createAuthorizationCode`、`exchangeAuthorizationCode`、`pollDeviceToken`、`refreshAccessToken`、`startDeviceAuthorization`、`approveDeviceUserCode`、`revokeToken`）；客户端标识常量来自 `@/server/oauth/constants`。
- 会话层：需要用户上下文的端点（authorize、device/approve）通过 `getSessionFromRequest` 校验登录态；userinfo 使用 `getSessionWithProfile` 直接获取用户资料。
- 错误处理：业务异常以 `OauthError` 抛出，由路由统一映射为 `{ error, error_description }` + 正确 HTTP 状态码；设备 approve 端点额外捕获 `AppError` 并返回 `{ error, message }`。
- 依赖方向单向：API route → server/oauth/service → 数据库/持久化；本模块不直接访问数据库或存储。
