- 每个 OAuth 端点以独立子目录下的 `route.ts` 暴露，文件内导出 `POST`/`GET` 函数作为路由处理器。
- 所有路由处理器顶部统一声明 `export const runtime = 'nodejs'` 与 `export const dynamic = 'force-dynamic'`，强制动态执行。
- 对 JSON 与 `application/x-www-form-urlencoded` 两种入参格式采用统一的 `readBody` 辅助函数进行兼容解析，只保留字符串值。
- 业务异常通过抛出 `OauthError`（或 `AppError`）表达，路由层在 catch 块中将其转换为 `{ error, error_description/message }` 响应并携带对应 HTTP 状态码。
- 需要登录态的端点在入口立即调用 `getSessionFromRequest`，未登录时直接返回 `{ error: 'login_required', ... }` 与 401。
- 对可选查询参数使用 `typeof x === 'string' ? x : defaultValue` 的安全解构模式，避免 undefined 被当作字面量传入下游服务。
