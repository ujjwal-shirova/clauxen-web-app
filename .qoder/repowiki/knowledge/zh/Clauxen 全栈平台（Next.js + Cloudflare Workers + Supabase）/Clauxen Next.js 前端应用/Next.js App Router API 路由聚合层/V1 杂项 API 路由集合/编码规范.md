- 受保护路由使用 `withApiHandler(async ({ session, request }) => {...}, { requireAuth: true })` 包裹，并在函数体内通过 `requireSession(session)` 取得用户对象。
- 成功响应统一通过 `jsonData(payload, status?)` 返回，而非直接 `Response.json`。
- 请求体参数在运行时进行类型检查与长度裁剪，非法值通过 `throw new AppError(message, statusCode, code?)` 抛出。
- 每个 route.ts 顶部声明 `export const runtime = "nodejs"` 与 `export const dynamic = "force-dynamic"`，长耗时流式端点再追加 `maxDuration`。
- 业务逻辑被抽离至 `@/server/services/*` 与 `@/server/repositories/*`，route 文件仅负责参数解析、鉴权与编排。
