该模块是 Next.js App Router 下 `src/app/api/v1/` 中一组互不隶属的 leaf 路由目录，每个子目录对应一个业务域（gifts、incognito、cookies、customize、integrations、webhooks、public-profiles、geo），并以文件路径直接映射 HTTP 方法：
- 认证型接口统一通过 `withApiHandler`（来自 `@/server/http/api-handler`）包裹 handler，并使用 `requireSession` 在需要时校验登录态；非认证型接口则直接使用原生 Next.js route export。
- 成功响应一律通过 `jsonData`（来自 `@/server/http/api-response`）包装 `{ data }` 结构体返回。
- 输入校验与错误抛出采用本地 `AppError`（`@/server/db/errors`），配合 `notFound` 返回 404。
- 业务逻辑下沉到 `@/server/services/*` 与 `@/server/repositories/*`，路由层只做参数解析、鉴权与编排；例如 gifts/purchase 委托 `giftService.purchaseGift`，customize/skills 委托 `customize.repository` / `user-skills.repository`。
- 流式端点（如 incognito/generate）直接 `new Response(stream)` 并附带 `CLAUXEN_STREAM_HEADERS` 与 `Cache-Control: no-cache, no-transform`。
- 所有 route.ts 均声明 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`，部分长耗时端点额外设置 `maxDuration`（如 incognito 的 300s）。
- 依赖方向单向：route → server/http* 中间件 → server/services|repositories → lib/* 工具与外部存储/计费服务。
