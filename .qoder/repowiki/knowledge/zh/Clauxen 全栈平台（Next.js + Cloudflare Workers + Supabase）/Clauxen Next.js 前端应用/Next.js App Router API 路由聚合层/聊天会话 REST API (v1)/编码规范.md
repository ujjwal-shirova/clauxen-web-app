- 路由文件顶部声明 `export const runtime = 'nodejs'` 与 `export const dynamic = 'force-dynamic'`，使端点运行在 Node.js 而非 Edge Runtime。
- GET/POST 处理器统一用 `withApiRouteParams<{ chatId: string }>` 解构 session/params/request，并用 `requireSession(session)` 获取用户 id。
- 需要资源权限的端点在 `withApiRouteParams` 的第二个参数传入 `{ requireAuth: true, requireChatAuth: true }`，由框架完成身份与所有权校验。
- 成功响应一律通过 `jsonData({ ... })` 返回标准信封结构，避免直接 `res.json`。
- 输入校验失败抛出 `new AppError(message, status, code?)`，未找到资源抛出 `notFound('...')`，保持错误类型统一。
- 对长耗时或可中断操作（如 generate）设置 `maxDuration = 300`，并在入口并行执行速率限制（`assertDurableRateLimit`）与边缘标志检查。
