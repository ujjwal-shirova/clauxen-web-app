基于 Next.js App Router 的目录路由：根 `route.ts` 处理聊天集合 GET/POST；`[chatId]/route.ts` 处理单聊 GET/PATCH/DELETE；子目录按资源维度拆分（`messages`、`generate`、`live`、`archive`、`share`、`transcript`、`title`、`pin`、`project`、`branches`、`research/[toolId]`、`search`、`generating`）。每个 handler 统一通过 `withApiRouteParams` 注入 `[chatId]` 与认证门控，并通过 `requireChatAuth` 校验用户-聊天归属。业务逻辑下沉到 `@/server/services/chat.service`、`@/server/repositories/*`，数据访问走 `@/server/db/pool`；生成流程由 `durable-generation` + `generation-jobs.repository` 驱动，`live` 端点从 Cloudflare Durable Object 读取实时 turn 状态并以 Postgres 为最终一致性回退。所有成功响应经 `jsonData` 包装，错误使用 `AppError` / `notFound`。
