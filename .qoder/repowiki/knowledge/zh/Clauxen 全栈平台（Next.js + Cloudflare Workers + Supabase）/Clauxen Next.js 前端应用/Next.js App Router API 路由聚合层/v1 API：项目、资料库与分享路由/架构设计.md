基于 Next.js App Router 的路由目录结构组织三个业务域：
- `projects/`：列出与创建项目（`route.ts`），以及按 `[projectId]` 获取详情、更新元信息、删除（`[projectId]/route.ts`）。
- `library/`：对当前会话用户的共享资料库执行列表、新建文件夹、重命名/移动、删除（`route.ts`）。
- `share/`：面向未认证访客的分享通道——`[token]/` 作为仅返回锁状态的“门”端点，`[token]/open/route.ts` 调用 `openSharedChat` 实际加载内容，`gate/route.ts` 暴露 Turnstile 站点密钥与 worker URL 供前端初始化。
所有路由统一通过 `withApiHandler` / `withApiRouteParams` 包装；已认证接口用 `requireSession` + `{ requireAuth: true }`，分享接口显式 `{ requireAuth: false }`。数据访问下沉到 `@/server/repositories/projects.repository` 与 `@/server/services/*` 层，响应经 `jsonData` 序列化并配合 `applySharePrivacyHeaders` 注入 CPO 头。每个文件声明 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`。
