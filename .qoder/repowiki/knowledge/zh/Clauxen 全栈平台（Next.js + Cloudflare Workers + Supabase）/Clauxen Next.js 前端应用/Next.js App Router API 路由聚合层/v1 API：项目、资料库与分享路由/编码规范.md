- 每个路由文件顶部固定导出 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"` 以禁用静态生成。
- 受保护路由使用 `withApiHandler` 包装 handler，并通过 `requireSession(session)` 解析用户上下文，同时传入 `{ requireAuth: true }`。
- 公开分享路由使用 `withApiRouteParams` 或 `withApiRoute`，配置 `{ requireAuth: false }`，并通过 `applySharePrivacyHeaders` 包裹响应以写入隐私头。
- 请求体先经 `request.json().catch(() => ({}))` 容错后再做字段校验与截断（如名称 120 字符、颜色正则 `#RRGGBB`、指令 8000 字符）。
- 错误处理通过 `AppError` 与 `notFound` 抛出，由上层统一转为 JSON 响应。
