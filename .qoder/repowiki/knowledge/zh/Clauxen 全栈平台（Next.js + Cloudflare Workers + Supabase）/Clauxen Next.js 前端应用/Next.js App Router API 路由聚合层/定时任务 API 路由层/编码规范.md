- 公开 API 统一通过 `withApiHandler` 或 `withApiRouteParams` 包装，并在选项 `{ requireAuth: true }` 中启用会话校验，再用 `requireSession(session)` 提取当前用户。
- 请求体解析采用 try/catch 包裹 `request.json()`，失败时抛出 `AppError` 或返回 400 JSON，并对字段做 `typeof` 白名单 + 别名兼容（如 `timeLocal`/`time_local`、`dayOfWeek`/`day_of_week`）。
- 内部端点统一在函数首行调用 `isScheduledTasksInternalRequest(request)` 校验令牌，未授权直接返回 401 JSON，不进入业务逻辑。
- 所有路由文件显式声明 `export const runtime = "nodejs"`，需要长耗时或动态路由时额外设置 `dynamic = "force-dynamic"`，由 `dispatch` 和 `execute` 分别设置 `maxDuration` 30 秒与 300 秒。
- 返回值统一经 `jsonData(...)` 封装，HTTP 状态码通过第二个参数显式传入（如 201、202）。
