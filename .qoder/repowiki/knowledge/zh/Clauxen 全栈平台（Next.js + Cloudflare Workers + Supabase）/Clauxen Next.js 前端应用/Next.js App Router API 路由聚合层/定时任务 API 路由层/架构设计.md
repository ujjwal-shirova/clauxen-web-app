模块按 Next.js App Router 约定拆为两层路由：
- `src/app/api/v1/scheduled-tasks/`：面向已认证用户的公开 API（GET/POST 列表与创建、`[taskId]` 子资源 GET/PATCH/DELETE、`[taskId]/run` 手动触发、`runs` 查询运行历史），通过 `withApiHandler` / `withApiRouteParams` 中间件完成会话校验与参数解构，再委托给 `@/server/services/scheduled-tasks.service` 与 `@/server/repositories/scheduled-tasks.repository`。
- `src/app/api/v1/internal/scheduled-tasks/`：仅内部调用端点，使用 `isScheduledTasksInternalRequest` + `SCHEDULED_TASKS_INTERNAL_TOKEN` 鉴权；`dispatch` 是 cron 入口，调用 `dispatchDueScheduledTasks` 产出持久化队列作业；`execute` 接收 `runId` 并调用 `executeScheduledRun`，再通过 `after()` 异步触发 `triggerContinuation` 以继续生成阶段。
依赖方向单向向外：route → services → repositories/db，外部依赖 `durable-generation` 中的 `generationExecutionOrigin` 与 `triggerContinuation` 编排跨阶段的持续生成流程。
