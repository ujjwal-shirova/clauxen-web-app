本模块是 Next.js App Router 的叶子路由集合，每个子目录对应一个 REST 端点（current/domains/members/scim-tokens/sso-connections），统一通过 `withApiHandler` 包装异步处理器，由 `@/server/http/api-handler` 注入 session 并集中映射错误；成功响应经 `jsonData` 包裹为 `{ data }` 信封。

- 依赖方向单向向外：路由层仅调用 `@/server/services/workspace.service` 中的工作区领域服务，不直接访问数据库或仓库。
- 认证通过 `requireAuth: true` 与 `requireSession` 双重保障，匿名用户返回 401。
- 所有路由声明 `runtime = 'nodejs'` 与 `dynamic = 'force-dynamic'`，因数据绑定当前用户会话与工作区上下文，不可缓存。
- sso-connections/route.ts 额外在路由层做敏感字段脱敏（按 key 正则匹配 secret/password/token/private/credential/certificate/signing/key）并设置 `Cache-Control: no-store, private`，体现该端点的私有性。
