- 每个路由文件以 `export const runtime = 'nodejs'; export const dynamic = 'force-dynamic';` 开头，显式禁用静态构建。
- 所有 HTTP 处理器使用 `withApiHandler(async ({ session, request }) => { ... }, { requireAuth: true })` 包裹，用户身份通过 `requireSession(session)` 提取。
- 响应体统一经 `jsonData(payload, status)` 返回，错误通过抛出 `AppError` 或 `notFound` 表达。
- 客户端传入的可变参数（如 planId、countryCode、maxTier）在创建订单前调用 `assertCheckoutClaimsMatchClientInput` 与服务端签发的 checkout session 声明做一致性校验。
- 业务编排集中在 `@/server/services/*`，仓储层集中在 `@/server/repositories/*`，路由仅负责参数解析与鉴权，不直接操作数据库。
