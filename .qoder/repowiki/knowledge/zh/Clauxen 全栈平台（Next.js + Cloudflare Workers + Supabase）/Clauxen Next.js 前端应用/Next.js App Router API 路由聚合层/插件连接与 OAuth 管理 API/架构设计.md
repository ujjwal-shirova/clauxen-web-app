基于 Next.js App Router 的 REST 端点集合，按资源划分子路由：
- `connect/[pluginId]/`：发起 OAuth 授权，根据请求来源（cross-site 或 popup）返回重定向或 `connectResultPage` HTML；依赖 `startPluginConnection`。
- `callback/`：OAuth provider 回调入口，交换 code 并调用 `completePluginConnection`，最终回写结果页。
- `oauth-client/`：提供 OIDC Client Metadata JSON，作为静态 client_id 源供支持该规范的 provider 使用。
- `connections/` 与 `connections/[connectionId]/`：列出用户已连接插件，并提供 GET/PATCH/DELETE 以查看工具/能力/活动日志、切换权限模式、启用禁用工具、断开连接。
所有路由均通过 `withApiRouteParams` 或 `withApiHandler` 包装，从 `@/server/http/route-params` 与 `api-handler` 注入 session 与参数校验；数据访问统一委托给 `@/server/repositories/plugin-connections.repository`，DTO 通过 `connection-dto` 序列化；业务编排集中在 `@/server/plugins/plugin-connect`、`connector-registry`、`catalog` 等 server 层模块。每个 route.ts 都声明 `runtime = 'nodejs'` 与 `dynamic = 'force-dynamic'`，避免 Edge Runtime 限制。
