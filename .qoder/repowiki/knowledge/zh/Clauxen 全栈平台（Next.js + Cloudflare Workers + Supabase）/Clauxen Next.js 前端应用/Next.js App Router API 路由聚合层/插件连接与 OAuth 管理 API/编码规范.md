- 路由文件通过 `withApiRouteParams<{ ... }>` 或 `withApiHandler` 包装 handler，并从上下文解构 `request`、`session`、`params`，而非直接读取 Next.js request 对象。
- 需要鉴权的路由在 handler 开头调用 `requireSession(session)` 抛出未认证错误；无需鉴权的连接入口则显式传入 `{ requireAuth: false }`。
- 数据库访问统一走 `@/server/repositories/plugin-connections.repository`，HTTP 层不直接操作数据库表。
- 响应体一律通过 `jsonData(...)` 序列化，错误则使用 `notFound` 或 `AppError` 构造结构化异常。
- 所有 route.ts 顶部固定声明 `export const runtime = "nodejs"` 与 `export const dynamic = "force-dynamic"`，以绕过 Edge Runtime 限制。
- OAuth 相关错误通过 `connectResultPage` 渲染 HTML 结果页，并根据 `PluginOAuthError` 实例区分 provider 错误消息与通用失败文案。
