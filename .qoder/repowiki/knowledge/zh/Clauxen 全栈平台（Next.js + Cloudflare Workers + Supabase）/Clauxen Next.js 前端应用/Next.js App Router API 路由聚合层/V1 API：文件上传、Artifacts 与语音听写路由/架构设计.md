模块由三组并列的 Next.js App Router 路由组成，均位于 `src/app/api/v1/` 下，遵循“薄路由 + 服务层”分层：
- `files/`：通过 `[fileId]/route.ts`（DELETE）、`presign/route.ts`（POST）和 `complete/route.ts`（POST）实现分片式对象存储上传流程，业务逻辑委托给 `@/server/services/files.service`，并在 avatar 场景联动 `avatar.service`。
- `artifacts/route.ts`：暴露 GET/POST 对 artifacts 进行列举与创建，依赖 `@/server/repositories/artifacts.repository` 做持久化，并内置 `ARTIFACT_KINDS` 白名单校验。
- `audio/dictation/`：`session/route.ts` 调用 `assemblyai/streaming-token` 获取临时 token 并返回流式参数；`[sessionId]/chunks/[sequence]/route.ts` 与 `[sessionId]/complete/route.ts` 为兼容前端而保留的无操作端点（音频不再持久化到 R2）。
所有路由统一通过 `withApiHandler` / `withApiRouteParams` 包装，使用 `requireSession` 鉴权、`jsonData` 封装响应，并通过 `assertDurableRateLimit` 在 dictation session 上施加 per-user 分钟级/小时级速率限制。每个 handler 都声明 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`。
