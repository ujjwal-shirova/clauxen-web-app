- 路由文件通过 `export const runtime = "nodejs"` 与 `export const dynamic = "force-dynamic"` 显式声明执行环境。
- HTTP 处理器统一使用 `withApiHandler` 或 `withApiRouteParams` 包裹，并以 `{ requireAuth: true }` 开启鉴权。
- 用户身份通过 `requireSession(session)` 提取，失败时由中间件抛出错误。
- 成功响应统一用 `jsonData(payload, status?)` 封装，失败则抛出 `AppError` 以携带 HTTP 状态码。
- 业务逻辑从路由中下沉到 `@/server/services/*` 或 `@/server/repositories/*`，路由只负责参数解析与编排。
- 对外部输入使用 Zod schema（如 dictation session）或手动类型断言 + 白名单校验（如 artifact kind），再进入服务层。
