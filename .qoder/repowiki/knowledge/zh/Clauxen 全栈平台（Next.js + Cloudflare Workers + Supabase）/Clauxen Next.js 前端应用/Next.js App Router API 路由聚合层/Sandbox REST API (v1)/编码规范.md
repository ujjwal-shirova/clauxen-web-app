- 每个路由文件以 `export const runtime = "nodejs"` + `export const dynamic = "force-dynamic"` 开头声明运行配置，长耗时端点追加 `maxDuration = 300`。
- 处理器通过 `withApiHandler` 或 `withApiRouteParams` 包裹，并在 `{ requireAuth: true }` 选项下强制鉴权。
- 进入业务逻辑前先调用 `requireSession(session)` 提取用户，并对沙箱相关操作调用 `assertSandboxOwnedBy(params.sandboxId, user.id)` 进行所有权校验。
- 返回值统一使用 `jsonData(...)` 包装后返回，避免直接 `Response.json`。
- 请求体通过 `await request.json()` 解析并使用 TypeScript 类型断言描述字段结构。
