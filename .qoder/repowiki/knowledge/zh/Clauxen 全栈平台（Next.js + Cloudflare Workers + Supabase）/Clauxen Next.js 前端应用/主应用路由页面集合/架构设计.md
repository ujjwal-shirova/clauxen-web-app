基于 Next.js App Router 的 (main) 路由组，根 layout.tsx 通过 MainLayout 组件为所有子路由注入统一的 Shell UI 与 StreamdownStyles；各功能域以独立目录组织（c/[chatId]、projects/[projectId]、settings/[tab]、customize、gift、library、new、plugins、pricing、upgrade、u/[username]、my-clauxen），其中带参数的路由在各自 layout.tsx 中通过 generateMetadata 动态生成 SEO 元数据（如 chatDocumentMetadata）。
- 根 page.tsx 为空占位页；error.tsx 是客户端错误边界，采用静默软重置 + 会话计数重试策略，不向用户展示任何错误 UI。
- 子级 layout 通常只透传 children，仅当需要覆盖 metadata 或注入特定逻辑时才实现自定义布局。
- 依赖方向单向：本模块消费 @/components/* 与 @/server/* 工具函数，不被业务组件反向引用。
