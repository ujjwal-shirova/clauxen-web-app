- 对话框组件统一以 `open` + `onOpenChange` 作为受控入口，由父组件管理打开/关闭状态。
- 需要挂载到 DOM 根节点的对话框（如 directory）通过 `react-dom/createPortal` 渲染到 `document.body`，并在服务端渲染时返回 `null` 避免水合差异。
- 长文本输入前统一用 `stripControlChars` 剥离 C0/DEL 控制字符，并通过常量（如 `SKILL_TITLE_MAX_LENGTH`、`SKILL_FIELD_MAX_LENGTH`、`SKILL_UPLOAD_MAX_BYTES`）做客户端长度或大小截断。
- UI 样式组合采用 `cn(chrome.overlay.dialog, ...)` 叠加 shadcn 组件默认样式与应用主题类，保持统一的 overlay 外观。
