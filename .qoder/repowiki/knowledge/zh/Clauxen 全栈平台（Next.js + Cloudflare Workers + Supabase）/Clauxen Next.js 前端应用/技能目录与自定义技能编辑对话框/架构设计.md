本模块是 `src/client/components/customize/` 下的 skills 子目录，包含三个独立的无状态 React 对话框组件：
- `directory.tsx`：通过 `createPortal` 将 `SkillDirectoryDialog` 渲染到 `document.body`，数据源来自 `@/lib/starter-skills-data.starterSkillsStructure`，在客户端用 `useMemo` 实现按名称/描述过滤和排序（`skill-creator` 置顶）。
- `instructions-dialog.tsx`：基于 shadcn Radix Dialog 的受控表单，负责收集 skill name / description / instructions，使用 `stripControlChars` 清理 C0/DEL 控制字符并按常量限制长度后调用父组件传入的 `onSave`。
- `upload-dialog.tsx`：基于 shadcn Dialog 的文件上传对话框，校验扩展名（`.zip/.skill/.md`）与大小上限（25 MB），调用 `@/lib/api/customize.uploadSkillFile` 完成上传。
依赖方向单向指向 UI 原子（`@/components/ui/dialog/input/button/textarea`）、应用样式（`@/lib/app-chrome`、`@/lib/utils.cn`、`@/lib/app-buttons`）以及 API 层（`@/lib/api/customize`、`@/lib/starter-skills-data`），组件之间相互独立、无内部共享逻辑。
