- Next.js 路由采用 App Router 目录约定，业务页面按 `(group)/path/page.tsx` 组织，API 端点按 `api/<domain>/<resource>/route.ts` 分组。
- 客户端状态通过 `client/contexts/` 下的 Context Provider 注入根布局，组件仅通过 hooks 读取，避免直接访问全局变量。
- HTTP 请求集中在 `client/hooks/use-*.ts` 中封装，UI 组件不直接调用 `fetch`，而是消费对应 hook 返回的状态与函数。
- 可复用交互原语统一放在 `client/components/ui/`，业务组件组合这些原子组件而非自实现按钮、弹窗、表单控件。
- Markdown 渲染走 `client/components/markdown-renderer.tsx` 及 `streamdown-*` 工具，聊天消息与深度研究输出均复用该管线。
