本模块由三个独立的 React 客户端组件组成，彼此无内部依赖：
- `gift-animation.tsx` 导出纯展示型 `GiftAnimation` 组件（SVG 礼盒图标 + 面板样式），被领取弹窗复用。
- `gift-claim-dialog.tsx` 是核心交互入口，通过 `createPortal` 将 `AnimatePresence` + `framer-motion` 动画的对话框挂载到 `document.body`，以受控 `open` 属性驱动显示；根据 `claimed`/`claiming`/`error` 状态在「已领取成功」和「待领取」两个视图间切换，并处理 Escape 键关闭、主题色渐变背景等细节。
- `gift-payment.tsx` 是兼容层，当托管结账重定向失败时显示的降级页面，仅包含一个返回按钮。
依赖方向单向向外：本模块消费 `@/components/ui/button`、`@/lib/utils`、`@/lib/app-buttons`、`@/lib/app-chrome` 及 `framer-motion`，不暴露业务逻辑或 API 调用，仅作为 UI 壳。
