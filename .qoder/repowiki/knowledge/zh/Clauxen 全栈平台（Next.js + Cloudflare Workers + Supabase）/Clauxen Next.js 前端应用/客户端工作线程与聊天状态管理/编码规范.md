- Web Worker 通过 `self.onmessage` 接收结构化 MessageEvent，并使用 discriminated union（如 `{ type: "rebuild" | "add" | "remove" | "query" }`）区分入站指令，出栈结果也携带 `type` 字段。
- Worker 与宿主之间的大对象通过 `postMessage` 的 `transfer` 选项直接转移 ArrayBuffer，避免拷贝开销。
- Worker 入口统一以 try/catch 包裹业务逻辑，出错时通过 `postMessage({ error })` 回传可读错误信息，由宿主层转换为 Promise reject。
- Store 中的复杂状态更新函数接受 updater 回调或新值两种签名（如 `setRecentChats`、`setBranchDataset`），以便兼容 zustand 的订阅选择器模式。
