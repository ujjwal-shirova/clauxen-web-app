模块由三个相互独立的文件组成：
- `markdown-renderer.tsx` 是入口编排层，导出 `MarkdownOrchestrator`（静态）、`MarkdownMessage`（流式/占位/轻量模式）和 `MarkdownRenderer`（薄包装），通过 `react-markdown` + `StreamingMarkdown` 渲染内容；当存在 `sources` 时调用 `convertCitationReferencesToLinks` 将模型引用语法转为链接，并用 `createCitationLink` 替换 `<a>` 渲染为内联 SourceChip。
- `code-block.tsx` 封装带语言标签与剪贴板复制的代码块，使用正则白名单 `SAFE_LANGUAGE_PATTERN` 过滤语言名后委托给 `@/lib/syntax-highlight` 的 `HighlightCode`，外层由 `@/components/markdown-styles` 的 `CodeBlockFrame` 提供样式与交互。
- `icons.tsx` 集中存放所有业务 SVG 图标，每个图标以命名函数导出，接受 `SVGProps` 并透传 props。
依赖方向单向向外：本模块仅消费 `@/components/streaming-*`、`@/components/markdown-shared`、`@/components/chat-sources`、`@/lib/syntax-highlight`、`@/lib/utils`，不被同级组件反向依赖，作为纯展示层被上层页面消费。
