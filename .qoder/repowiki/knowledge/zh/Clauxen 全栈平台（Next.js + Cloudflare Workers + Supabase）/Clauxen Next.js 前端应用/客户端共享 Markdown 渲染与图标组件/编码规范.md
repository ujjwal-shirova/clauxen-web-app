- 所有组件标注 "use client" 指令，表明它们运行在浏览器端。
- Markdown 相关组件通过 `detailLevel`（placeholder/plain/full）与 `lightweightStream` 等 prop 组合切换不同渲染路径，而非拆分为多个组件。
- 当消息附带 sources 时，先调用 `stripReferenceDefinitions` / `stripTrailingCitationClusters` 清理内容，再将引用语法转换为链接以便注入 SourceChip。
- 图标组件统一以命名函数形式导出，接收 `SVGProps<SVGSVGElement>` 并透传 props，内部使用 `fill="currentColor"` 支持主题色。
- 外部传入的语言标识通过正则白名单 `SAFE_LANGUAGE_PATTERN` 校验后再传递给语法高亮器，非匹配值降级为 "code"。
