- 服务端 route 统一导出 `runtime = "nodejs"` 与 `dynamic = "force-dynamic"`，避免静态构建对动态认证流的限制。
- 通过自定义 `cookies.getAll / setAll` 包装 Supabase server client，在 `setAll` 中统一注入 `sameSite: "lax"`、生产环境 `secure: true` 以及 `/` path，确保 Cookie 安全策略一致。
- 所有外部跳转目标先经 `safeNext` 类函数校验（以 `/` 开头、非 `//`、根路径映射到 `/new`），防止开放重定向漏洞。
- 错误与异常统一通过 `NextResponse.redirect(origin, ...)` 带 query 参数返回，如 `?auth=1&error=...`，并在响应上设置 `Cache-Control: no-store`。
- 用户会话建立后统一调用 `isDisposableEmailSafe` 检查邮箱，若命中则主动 `signOut` 并引导至登录页附带错误信息。
