本模块由一组相互独立的 React Context Provider 组成，每个文件封装一个横向领域：
- `auth-context.tsx`：基于 Supabase 的完整认证流程（登录/注册/OAuth/Magic Link/Phone OTP），维护用户会话、加载态和 OAuth 导航清理。
- `auth-gate-context.tsx`：在需要认证的 UI 处打开登录弹窗并支持 deep-link 恢复，依赖 `useAuth` 而非直接调用 API。
- `chat-session-context.tsx`：聚合 `useChatApi` 与模型/推理强度选择，作为主 shell 的单例聊天会话来源。
- `app-preferences-context.tsx`：管理主题、字体、动效、侧边栏宽度等偏好，先本地渲染再异步同步到 Supabase settings，含防抖持久化。
- `artifact-viewer-context.tsx`：控制 Artifacts 预览/代码视图开关与活跃 artifact。
- `follow-up-prompt-context.tsx`：轻量级开关上下文，供下游组件决定是否展示 follow-up prompt。

依赖方向自下而上：auth-gate 依赖 auth；preferences 依赖 auth；其余彼此解耦。所有 context value 通过 `useMemo` 稳定引用，并提供 `useOptionalXxx` 钩子以安全地读取 null。
