- 每个 Context 同时导出 Provider 组件与同名 `useXxx` 钩子，并在钩子中抛错提示未包裹于 Provider 内。
- 额外提供 `useOptionalXxx` 钩子返回 `Context | null`，用于可被 Provider 外渲染的组件安全消费。
- Context value 对象通过 `useMemo` 包裹并按 observable 字段列出依赖，以保证方法引用稳定、避免子组件无谓重渲染。
- Provider 顶部标注 `'use client'`，且对浏览器 API 的使用均做 `typeof window !== 'undefined'` 守卫以兼容服务端渲染。
