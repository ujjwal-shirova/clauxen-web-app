模块由三个协作的 React 客户端组件构成：
- `subscription.tsx` 是计划选择器，渲染个人/组织计划卡片、价格对比和「Current plan」CTA，通过 `onSelectPlan(planId, billingCycle, maxTier)` 回调将用户选择向上抛出；它从 `@/lib/plans-catalog` 读取定价元数据并复用 `billing-checkout` 导出的 `MaxTier` 类型。
- `billing-checkout.tsx` 是核心结账编排器，维护会话创建、座位数量、账单地址、GSTIN、支付方式标签页等状态，调用 `@/lib/api/billing` 完成 `createBillingOrder` / `createCheckoutSession` / `upsertBillingAddress` / `verifyBillingPayment` 等后端交互，并桥接 Razorpay 自定义脚本 (`startCardWithRazorpayCustom`、`startNetbankingWithRazorpayCustom`)、Apple Pay 检测与 UPI QR 弹窗。
- `checkout-page-view.tsx` 是最外层路由视图，仅负责把 URL 参数转译为 `BillingCheckout` props，并在支付成功后写入 sessionStorage 并通过 `window.location.replace('/new?checkout=success')` 导航回新对话页以触发支付弹窗。
依赖方向单向向外：本模块消费 `@/components/*` 子组件（`CheckoutForm`、`CheckoutPayCta`、`CheckoutUpiQrModal`、`CheckoutBootstrapping`、`checkout-billing-address` 等）、`@/lib/*` API 与工具，但不被同层其他组件反向引用，作为结账入口的叶子组件集。
