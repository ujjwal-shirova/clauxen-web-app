- 对外暴露的组件通过具名接口定义 props 类型，并将共享类型（如 `MaxTier`）重新导出供 `subscription.tsx` 等其他组件消费。
- 副作用与导航操作统一放在最外层视图（`checkout-page-view.tsx`），内层 `BillingCheckout` 仅通过 `onBack` / `onPaymentSuccess` 回调向上汇报结果。
- 面向印度的格式化（货币、日期、GSTIN、时区）一律使用 `toLocaleString('en-IN', { timeZone: 'Asia/Kolkata' })` 或专用工具函数集中处理。
- 可选配置字段采用显式默认值参数形式（如 `returnPath = "/new"`、`needsSessionRemint = false`、`giftCheckout = null`）而非解构默认值。
