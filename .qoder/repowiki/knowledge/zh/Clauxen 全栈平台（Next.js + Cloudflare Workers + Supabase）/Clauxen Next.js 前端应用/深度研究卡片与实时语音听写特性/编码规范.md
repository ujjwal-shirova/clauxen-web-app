- 长生命周期的外部资源（WebSocket、MicrophoneCapture、计时器）统一保存在 `useRef`，并通过 `releaseRefs` / `clearWatchdogs` 在 finish 或卸载时成对清理，避免内存泄漏。
- 易变的运行期状态同时维护一份 `xxxRef`（如 `statusRef`、`finishRef`）与 `useState`，确保异步回调能读取到最新值而不被闭包捕获旧值。
- 转写状态与文本操作集中在 `transcript.ts` 中以纯函数形式实现（`applyAssemblyTurn`、`insertTranscriptAtCaret`、`splitDraftAroundCaret`），使 Hook 层只做调度与副作用编排。
- 对外部 I/O（网络、音频、定时器）采用 Promise + AbortController 模式：请求附带 signal，并在 effect 返回中 abort，保证取消语义正确。
- 组件使用 Radix UI 原语（Dialog.Root、DropdownMenu.Root 等）而非自定义弹窗/下拉，样式通过 className 与 CSS 变量（如 `--ui-border-subtle`、`--app-panel-bg`）注入。
