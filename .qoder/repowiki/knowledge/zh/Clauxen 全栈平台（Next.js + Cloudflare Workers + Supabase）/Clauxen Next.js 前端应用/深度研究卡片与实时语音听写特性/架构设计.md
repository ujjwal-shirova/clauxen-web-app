模块分为两个相对独立的子域：
- `components/` 下的 `DeepResearchPlanCard` 和 `ResearchReportCard` 是 React 客户端组件（均带 `"use client"`），前者作为薄包装将加载态、流式态与持久化的 `DurableResearchPlanCard` 统一暴露；后者通过 `apiFetch` 拉取 `ResearchReport` 并渲染 Markdown、来源、Agent 活动日志，并提供 Markdown/Word/PDF 导出。
- `features/dictation/` 实现一条自包含的实时听写管线：`microphone-capture.ts` 用 Web Audio API + `ScriptProcessorNode` 以 16 kHz PCM 流式采集麦克风音频；`assemblyai-stream.ts` 封装 `AssemblyAiStreamingConnection` 类，通过 WebSocket 向远端 `/v3/ws` 发送音频帧并解析 `Turn` / `Termination` / `error` 事件；`transcript.ts` 维护无副作用的 `StreamingTranscriptState`（已确认分段 + 部分片段）并提供插入、裁剪、拼接等纯函数；`types.ts` 集中定义会话响应、状态机与事件类型；`use-streaming-dictation.ts` 作为 Hook 组合上述三类能力，管理连接、静音/时长 watchdog、草稿拆分与光标重基线，并通过 `onDraftChange` 回调把增量转写落回编辑器。
依赖方向单向：Hook → (microphone-capture | assemblyai-stream) → transcript/types，组件不直接依赖听写逻辑。
