模块以 `agent-transcript.tsx` 作为单条消息的入口（`AgentTranscriptView`），根据 `message.agentTrace.steps` 把步骤拆分为 narration / activity 两类并分别渲染；`agent-trace-view.tsx` 提供带折叠/展开动画的活动账本（ledger）视图，内部通过 `AgentToolBlock`（`agent-tool-blocks.tsx`）分发到具体工具卡片（搜索、地图、代码、深度研究计划等）。`agent-message-content.tsx` 是外部消费方适配层，统一在 Agent 模式下委托给 `AgentTranscriptView`，在非 Agent 模式下回退到普通助手内容渲染。`create-file-stream-block.tsx`、`ask-user-input-card.tsx`、`artifact-file-card.tsx`、`agent-file-block.tsx` 是面向特定 `AgentStep.kind` 的可插拔块组件；`agent-trace-primitives.tsx` 提供 shimmer/text 等共享原语，`agent-morph-dots.tsx`、`agent-work-cursor.tsx`、`agent-favicon-stack.tsx` 提供状态指示器。依赖方向单向向下：本模块仅消费 `@/lib/agent-trace`、`@/lib/types`、`@/components/ui/bootstrap-icon` 等底层库，不被同级其他业务组件反向依赖。
