- 所有全屏预览组件（Image/Video/Document Lightbox）统一通过 `createPortal` 渲染到 `document.body`，并以 `open` 状态控制挂载。
- Lightbox 在打开时注册 `window` 的 `Escape` 键盘事件并临时设置 `document.body.style.overflow = 'hidden'`，关闭时恢复原值，形成统一的模态行为模式。
- 附件数据统一使用联合类型 `ComposerAttachment | MessageAttachment`，并通过 `kind` 字段进行分支判断，而非按文件扩展名或 MIME 判断。
- 预览资源 URL 统一经 `filePreviewSrc(file)` 获取，失败时回退到 `durableFileContentUrl(file.fileId)`，避免硬编码路径。
- 可访问性方面，弹窗使用 `role="dialog"` + `aria-modal="true"` + `aria-label`，缩略图移除按钮通过 `onKeyDown` 同时响应 Enter 和 Space。
