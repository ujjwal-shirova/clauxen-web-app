模块按「行内缩略图 → 横向滚动条 → 全屏预览弹窗」三层组织：
- 行内展示层：`attachment-chip.tsx` 根据 `file.kind`（image/video/document）渲染不同缩略图，支持上传中/错误态；`attachment-strip.tsx` 仅提供带 `scrollbar-hide` 的横向容器。
- 预览宿主层：`attachment-preview-host.tsx` 作为单一入口，依据 `file.kind` 分发到对应 Lightbox，并统一计算 `previewUrl`（来自 `filePreviewSrc`）。
- 具体 Lightbox 层：`attachment-image-lightbox.tsx`、`attachment-video-lightbox.tsx`、`attachment-document-preview.tsx` 各自实现全屏弹窗，均通过 `react-dom/createPortal` 挂载到 `document.body`，并处理 Escape 关闭与 body overflow 锁定。
- 辅助功能：`streaming-dictation-text.tsx` 独立于附件体系，消费 `@/features/dictation/types` 的 `DictationStatus`，以空格切分增量文本并保持与 textarea 一致的字体度量。
依赖方向单向向外：本模块仅消费 `@/lib/composer-attachments`（类型与 URL 工具）、`@/components/ui/bootstrap-icon` 图标、`@/lib/utils` 的 `cn`，不被其他 composer 子模块反向引用。
