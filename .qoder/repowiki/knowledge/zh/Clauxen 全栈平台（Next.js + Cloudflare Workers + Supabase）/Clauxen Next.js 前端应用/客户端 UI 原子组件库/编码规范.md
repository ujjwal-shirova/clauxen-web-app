- 组件统一使用 `React.forwardRef` 暴露原生 ref，并通过 `displayName` 命名以便调试。
- className 拼接统一走 `cn(...)` 工具函数，将默认 Tailwind 类与调用方传入类合并。
- 支持多态样式的组件通过 `cva` 声明 variants/defaultVariants，并以 `VariantProps<typeof xxx>` 扩展 props 类型。
- 复合组件按子部分拆分为多个 forwardRef 组件并批量 export（如 Card/CardHeader/CardContent）。
- 需要宿主上下文的组件（如 Sidebar）通过 `React.createContext` + 自定义 hook（`useSidebar`）提供，并在未包裹时抛出错误。
- 客户端专属功能组件（sidebar、chart）以 `'use client'` 指令开头，服务端渲染无关的纯展示组件则省略该指令。
