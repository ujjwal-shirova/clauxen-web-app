本模块是 `src/client/components/ui/` 下的原子级 React 组件库，每个文件导出一个独立组件（如 `Button`、`Input`、`Card`、`Sidebar`、`Chart`），无内部子目录。
- 样式层：统一通过 `@/lib/utils` 的 `cn` 合并 Tailwind 类名；可变样式（variant/size）一律使用 `class-variance-authority` 的 `cva` + `VariantProps` 声明（见 `button.tsx`、`badge.tsx`、`kbd.tsx`）。
- 交互层：所有复合/状态型组件基于 Radix UI 原语（`@radix-ui/react-slot`、`*` dialog/sheet/popover/toast 等）实现无障碍与键盘行为。
- 主题层：全部样式以 Tailwind 语义色变量（`bg-primary`、`text-muted-foreground`、`--radius-*`、`--icon-size`）表达，不直接写死颜色值。
- 复杂组件自包含：`sidebar.tsx` 在内部维护 `SidebarContext`、cookie 持久化与移动端 `Sheet` 切换；`chart.tsx` 封装 Recharts 并内置 ID/颜色白名单校验。
- 依赖方向：本模块仅依赖 `@/lib/utils`、`@/hooks/*` 以及外部库（Radix、Recharts、Tailwind），被上层 `components/plugins/*` 等业务组件引用，自身不反向依赖业务逻辑。
