模块以 React 组件为入口、数据层与类型定义解耦的扁平结构：
- 类型与数据源：`types.ts` 声明 `MarketplacePlugin` / `MarketplaceCatalog` / `CustomMarketplace` 等核心类型；`marketplace-catalog.json` + `catalog.ts` 提供只读目录查询（`pluginById`、`pluginsByIds`、`pluginMatches`、`filteredSections`）。
- 状态与 API 层：`use-plugin-connections.ts` 通过 `sessionFetch` 调用 `/api/v1/plugins/{connections,availability}`，并弹出子窗口走 `/api/v1/plugins/connect/:id` 完成 OAuth 重定向，使用 `postMessage('clauxen:plugin-connected'|'clauxen:plugin-connect-failed')` 与父页通信，封装 `usePluginConnections` hook 暴露 `connect/disconnect/refresh` 及 `ConnectionDetails` 获取能力。
- 视图层：`marketplace-view.tsx` 作为页面壳，按 `discover` / `installed` 标签组织分类区块与搜索；`plugin-detail-page.tsx` 渲染单个插件的工具/资源/Prompts 列表、权限开关与活动日志；`plugin-mark.tsx` 是卡片复用单元；`plugin-copy.ts` 提供文案常量；`plugin-details.ts` 注入额外静态详情。
- 依赖方向单向：视图 → catalog/use-plugin-connections → types；不反向引用。所有对外导出集中在 `index.ts`。
