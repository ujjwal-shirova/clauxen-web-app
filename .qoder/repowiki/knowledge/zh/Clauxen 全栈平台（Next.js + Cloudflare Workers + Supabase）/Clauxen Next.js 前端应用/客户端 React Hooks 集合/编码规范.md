- 每个 Hook 文件以 `'use client';` 指令开头，确保可在浏览器端直接 import。
- 复杂 Hook 通过组合多个内部 state/ref 与 `useCallback`/`useEffect` 暴露稳定接口，并将副作用下沉到 `@/lib/*` 工具函数（如 settings merge、chat store bridge）。
- 对外 API 通过独立的 `type` 声明（如 `UseChatOptions`、`StreamDeltaHandler`、`SettingsPatch`）与 Hook 同名文件组织，便于类型消费者按需导入。
- 需要跨组件共享的全局副作用（Toast、Auth、Overlay）采用模块级单例（reducer + listeners 数组、context re-export）而非局部 state。
- 异步持久化操作采用乐观更新 + 延迟去抖模式（如 `use-settings.ts` 中的 `schedulePersist` 120ms 合并），避免频繁后端请求与 UI 抖动。
