该模块是纯客户端 Hook 库，每个文件以 `use-` 前缀导出一个独立 Hook，遵循单一职责拆分：
- 业务域 Hook：`use-chat.ts`（统一入口，委托给 `useChatApi`）、`use-settings.ts`（含本地去抖合并与持久化）、`use-auth.ts`（薄包装重导出 `@/contexts/auth-context`）、`use-research.ts`、`use-artifacts.ts`。
- 数据流层 Hook：`use-chat-api.ts` 聚合 Supabase 同步、设备缓存、分支消息、标题生成、错误映射与 Vercel AI SDK 流式响应；`use-ai-stream.ts` 负责解析 Clauxen SSE / UI message stream 事件并分派到回调。
- UI 状态 Hook：`use-toast.ts` 实现基于 reducer + listeners 的全局 Toast 总线（受 react-hot-toast 启发）；`use-app-notifications.tsx`、`use-app-overlays.tsx`、`use-sidebar-state.ts`、`use-document-title.ts` 管理页面级 UI 状态。
- 基础设施 Hook：`use-is-client.ts`、`use-mobile.tsx`、`use-minimum-loading.ts`、`use-instant-navigate.ts`、`use-keyboard-shortcuts.ts`、`use-clear-auth-busy-on-return.ts` 等。
所有 Hook 均以 `'use client';` 指令标记，依赖方向单向向下：Hook → `@/lib/*`（API、store、类型定义）→ `@/components/*`（仅 UI 展示组件），不反向被 lib 或 server 代码引用。
