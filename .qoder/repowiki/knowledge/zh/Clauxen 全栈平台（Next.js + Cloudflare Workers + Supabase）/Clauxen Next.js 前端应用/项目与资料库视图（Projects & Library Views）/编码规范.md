- 每个页面都是一个独立的 "use client" 组件，通过 `useEffect` 在挂载时调用 API，并用 `useState` 维护 loading/error/data 三元状态。
- UI 组件统一从 `@/components/ui/*` 导入（Dialog、DropdownMenu、Popover、Skeleton 等），不自行实现模态框或下拉菜单。
- 样式使用 Tailwind 原子类组合 CSS 变量（如 `bg-[var(--app-panel-bg)]`、`text-[var(--ui-fg)]`），避免硬编码颜色值。
- API 调用集中在 `@/lib/api/*` 模块中，视图层只消费函数导出，不直接拼 URL。
- 可复用的视觉元素（如项目图标）被抽到同级子目录（`project-icon.tsx`）并通过 named export（`ProjectMark`、`ProjectIconPicker`）供多个视图复用。
