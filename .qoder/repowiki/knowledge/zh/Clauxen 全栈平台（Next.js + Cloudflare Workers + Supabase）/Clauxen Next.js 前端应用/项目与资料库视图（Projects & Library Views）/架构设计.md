模块由三个并列的 React "use client" 视图组成，各自独立承担一个路由页面：
- `library-view.tsx`：实现完整的文件/文件夹浏览器，包含过滤（all/folders/documents/images/code）、排序、list/grid 双视图模式、上传/重命名/移动/删除等交互，通过 `@/lib/api/library` 与 `uploadUserFile` 与后端通信。
- `projects/projects-view.tsx`：项目管理主视图，负责项目列表、创建/编辑/删除、聊天会话嵌入、记忆策略（project-only vs default）配置；依赖 `@/lib/api/projects` 和 `@/lib/api/chats`，并通过子组件 `./project-icon.tsx` 提供的 `ProjectIconPicker` / `ProjectMark` 复用图标选择器。
- `my-clauxen-view.tsx`：个人使用统计页，通过 `sessionFetch("/api/v1/my-clauxen")` 拉取数据并在 closeness/growth 两个 tab 间切换，内嵌 `ActivityHeatmap` 与 `SelfGrowthGraphic` 子组件展示热力图与成长曲线。

所有视图共享同一套 UI 基础设施：`@/components/ui/*`（Dialog、DropdownMenu、Popover、Skeleton、bootstrap-icon）、`@/hooks/use-toast`、`@/components/app-layout-context` 与 `MobilePageHeader`。数据获取统一采用服务端 fetch（`sessionFetch` 或专用 API 模块），状态以本地 `useState` + `useEffect` 驱动，无跨视图共享状态。
