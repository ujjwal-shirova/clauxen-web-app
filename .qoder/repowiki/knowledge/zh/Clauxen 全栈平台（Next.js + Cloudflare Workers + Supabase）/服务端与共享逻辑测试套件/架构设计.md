测试按被测模块横向组织，每个 `*.test.ts` / `*.test.mjs` 对应一个 src 子域（deep-research、scheduled-tasks、cloudflare-runtime、auth-session、background-generation 等），并通过独立扩展名区分运行环境：`.mjs` 用于 Node ESM + esbuild 动态构建场景（如 auth-session.test.mjs 通过 esbuild 注入 service doubles 加载 JWT 模块），`.ts` 用于常规 TypeScript 单测。
- 纯函数/工具层测试直接 import `../src/shared/lib/*` 或 `../src/server/services/*`，使用 `node:test` + `node:assert/strict`。
- Cloudflare 相关测试（cloudflare-runtime.test.ts）直接导入 cloudflare 运行时模块，依赖 `@cloudflare/workers-types`。
- 集成测试（background-generation.integration.ts、durable-research.integration.ts）启动真实 Next.js 实例并连接 Supabase，需外部服务凭据。
- 生产冒烟脚本（scheduled-tasks.production-smoke.ts）独立于 test runner，用于 CI 生产环境验证。
- 测试数据通过 SQL fixture（background-generation.database.sql）和硬编码计划对象提供。
