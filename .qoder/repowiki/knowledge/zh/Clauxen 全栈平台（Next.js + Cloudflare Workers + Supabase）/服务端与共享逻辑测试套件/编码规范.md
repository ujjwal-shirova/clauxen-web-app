- 测试文件统一使用 `import { test } from "node:test"` 与 `assert from "node:assert/strict"`，断言采用 `assert.deepEqual` / `assert.rejects` / `assert.throws` 风格。
- 被测源码通过相对路径 `../src/...` 直接导入，避免引入项目包名，保证测试与实现一一对应。
- 需要外部依赖（Next.js、Supabase、Cloudflare Durable Objects）的场景拆分为 `.integration.ts` 或 `.production-smoke.ts` 独立文件，与普通单元测分离。
- 对不可控副作用（数据库连接、HTTP 服务器、child_process）通过内嵌 `createServer`、`spawn` 或 `requestResource` 回调进行资源生命周期验证。
