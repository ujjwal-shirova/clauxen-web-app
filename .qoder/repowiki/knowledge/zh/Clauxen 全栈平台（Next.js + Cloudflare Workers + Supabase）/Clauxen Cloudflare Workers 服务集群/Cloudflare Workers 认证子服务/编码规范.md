- 所有 HTTP 响应统一使用 `json()` 辅助函数返回 `application/json`，并附加 CORS 或安全头（如 `Cache-Control: no-store, private`、`X-Content-Type-Options: nosniff`）。
- 外部输入先通过 `boundedText`/`safeAppOrigin`/`ensure` 等校验器进行长度、URL 协议、参数唯一性等防御性解析，再进入业务逻辑。
- 敏感值（OTP、magic token、OAuth state、cookie secret）均以 SHA-256 哈希形式存储在 KV/Durable Object 中，比较使用恒等时间比较 `timingSafeEqual`。
- Worker 入口采用默认导出的 `ExportedHandler` 对象（`satisfies ExportedHandler<...Env>`），环境变量通过 TypeScript 接口声明并由 Wrangler 注入类型。
- OAuth 流程状态机通过 Durable Object 的单行 SQL 表 + alarm 实现阶段转换与过期清理，对外暴露 `init/take/complete/exchange/userinfo` 原子方法。
