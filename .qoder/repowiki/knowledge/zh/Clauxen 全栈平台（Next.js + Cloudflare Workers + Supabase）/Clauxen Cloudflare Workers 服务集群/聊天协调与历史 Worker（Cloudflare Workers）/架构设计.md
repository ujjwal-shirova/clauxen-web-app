模块包含两个独立的 Cloudflare Workers，分别通过各自的 `wrangler.toml` 部署：
- `workers/chat-coord`：实现 `ChatCoord` Durable Object，以 `ctx.storage` 持久化 lease 与 turn 记录，通过 `acquire/heartbeat/release/requestStop/status` 暴露分布式租约 API；使用 `setAlarm` 统一调度租约过期与 24h 后的 Supabase 归档。
- `workers/chat-history`：HTTP Handler Worker，通过 `postgres` 驱动经 Hyperdrive 连接 Supabase，并提供 JWT 校验（缓存于 Cache API）、消息分页、聊天列表、R2 归档与 Queue 异步 warm+archive 流水线。
两者通过 `CHAT_COORD` DO 绑定与内部 token 机制协作，history worker 调用 coord 完成并发控制，coord 在终端状态时触发归档 alarm。
