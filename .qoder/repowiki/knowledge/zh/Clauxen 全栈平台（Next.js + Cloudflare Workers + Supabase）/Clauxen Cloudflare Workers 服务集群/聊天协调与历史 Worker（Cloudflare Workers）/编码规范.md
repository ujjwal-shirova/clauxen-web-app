- Worker 入口统一通过 `export interface Env` 声明环境变量绑定（如 `SUPABASE_URL`、`CHAT_COORD`、`HYPERDRIVE`），并在运行时按可选绑定回退。
- 对外响应统一由 `json(data, status, extraHeaders, cors)` 辅助函数构造，并附带 CORS 头与 `x-clauxen-cache` 等自定义头部。
- 敏感路径通过 `CHAT_HISTORY_INTERNAL_TOKEN` / `CHAT_COORD_INTERNAL_TOKEN` 进行内部鉴权，外部请求走 JWT 或 Origin 白名单校验。
- 长耗时任务（归档、warm）通过 `ctx.waitUntil` 投递到 `HISTORY_JOBS` Queue，消费者侧配置 `max_batch_size`、`max_retries` 与 DLQ。
