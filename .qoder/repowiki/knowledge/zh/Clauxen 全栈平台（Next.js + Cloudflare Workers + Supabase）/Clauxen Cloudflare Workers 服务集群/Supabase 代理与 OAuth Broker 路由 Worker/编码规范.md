- 对外错误统一通过 `error(status, message)` 工厂返回 JSON，并附带 `Cache-Control: no-store`、`X-Clauxen-Proxy: 1`、`Access-Control-Allow-Origin: *` 响应头。
- 所有外部输入在转发前进行严格白名单校验（hostname、protocol、pathname 正则、HTTP method 列表），非法请求一律返回 4xx。
- 敏感请求头（host/cookie/forwarded/x-forwarded-*/x-real-ip/sb-forwarded-for/cf-*）在转发上游前显式删除，防止主机劫持与请求伪造。
- Worker 配置集中声明于 `wrangler.jsonc`，包括 routes、services binding、ratelimits、observability 与 vars，源码中仅引用常量。
