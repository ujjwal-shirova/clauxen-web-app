单入口 Cloudflare Worker（`src/index.ts`），通过 `ExportedHandler<Env>` 默认导出处理函数。内部按职责分层：
- 主机与路径白名单校验：仅允许 `HOST=auth.clauxen.com` 且 pathname 匹配 `/.../v1` 服务前缀；拒绝 `/auth/v1/admin*`。
- 速率限制：对 `/auth/v1/*` 非 OPTIONS 请求使用绑定到 KV 命名空间 `AUTH_RATE_LIMIT` 的 Durable Object 限流（120 req/min/IP）。
- 上游转发：构造固定目标 `UPSTREAM=https://ntplcfsbcyhiqklkbldk.supabase.co`，复制 pathname/search，删除 `host/cookie/forwarded/x-forwarded-*|x-real-ip/sb-forwarded-for/cf-*` 等不受信任头部，禁用缓存 (`cf.cacheTtl: 0`)。
- OAuth 重定向改写：当 provider 为 github/gitlab 且 `BROKER_PROVIDERS` 包含时，把 `provider` 替换为 `custom:clauxen-{provider}`，使 Supabase 调用自有 `clauxen-oauth-broker`。
- WebSocket 透传：上游返回 101 时直接回传，保留 Realtime 升级。
- OAuth Broker 分流：若请求 origin 为 `https://auth.clauxen.com` 且 path 以 `/oauth/` 开头或 `/auth/v1/callback?state=clx.*`，则委派给绑定的 `OAUTH_BROKER` Fetcher。
依赖方向单向：本 Worker 仅被 `clauxen-oauth-broker` 作为自定义 OAuth provider 反向调用，不依赖其他业务模块。
