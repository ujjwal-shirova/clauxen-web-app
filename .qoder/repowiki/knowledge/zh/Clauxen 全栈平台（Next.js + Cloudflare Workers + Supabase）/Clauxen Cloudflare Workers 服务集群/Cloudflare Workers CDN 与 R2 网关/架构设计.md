本模块包含两个并列的 Cloudflare Worker 子项目，各自拥有独立的 `package.json`、`wrangler.toml` 和 `src/index.ts` 入口：
- `workers/cdn/`（`clauxen-cdn`）：通过 `CDN_BUCKET` 绑定读取 R2 中的 `plugin-icons-bundle.tar`，在内存中解析 tar 归档并以 `/plugins/icons/<name>.png|svg|...` 等路径分发；首次请求时缓存到全局 `bundleCache`，响应经 `caches.default` 做边缘缓存，并附带 `immutable` 与长 max-age。
- `workers/r2-gateway/`（`clauxen-r2-gateway`）：通过 `IMAGES`/`DOCUMENTS`/`ARTIFACTS`/`USER_FILES`/`ATTACHMENTS` 多个 R2 桶绑定暴露统一 API，使用 `bucketForName` 路由到具体桶；鉴权走 Supabase Auth（`verifySupabaseJwt` 调用 `/auth/v1/user`），仅允许以 `users/{userId}/` 或 `avatars/{userId}/` 前缀写入，公共路径 `public/` 及 UUID avatar 可匿名读取。

依赖方向单向：Workers → Cloudflare R2（通过 `R2Bucket` binding）与外部 Supabase Auth；两 Worker 之间无相互引用，均通过 wrangler 的 `[[r2_buckets]]` 声明式绑定接入存储。
