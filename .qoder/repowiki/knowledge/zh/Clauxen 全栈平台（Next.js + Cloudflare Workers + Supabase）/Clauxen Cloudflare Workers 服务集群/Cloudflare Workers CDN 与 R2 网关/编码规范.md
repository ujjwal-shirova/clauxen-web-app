- Worker 入口统一导出 default 函数 `(request, env, ctx) => Response`，并通过 `export interface Env` 声明绑定的 R2 bucket 与环境变量。
- 健康检查端点统一暴露为 `/health`，CORS OPTIONS 请求直接返回允许的 headers 而不经业务逻辑。
- JSON 响应通过统一的辅助函数（如 r2-gateway 中的 `json()`）构造，固定设置 `content-type: application/json` 与可选 extra headers。
- 对 R2 对象键进行安全校验：拒绝包含 `..` 或 `/` 前缀的 key，并要求用户数据必须落在 `users/{userId}/` 或 `avatars/{userId}/` 前缀下。
- 私有对象下载强制设置 `cache-control: private, no-store` 并附加 `vary: authorization`，防止共享边缘缓存泄露用户数据。
