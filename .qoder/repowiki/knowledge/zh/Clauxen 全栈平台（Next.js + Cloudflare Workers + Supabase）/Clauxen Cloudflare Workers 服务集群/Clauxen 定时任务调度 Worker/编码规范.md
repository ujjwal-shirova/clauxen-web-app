- 对外部 HTTP 调用统一通过 `appFetch(env, url, init)` 封装，优先走 `env.APP` Private Service Binding，失败时回退到原生 `fetch`。
- 内部服务间认证采用双通道：同时校验 `Authorization: Bearer <token>` 与 `x-clauxen-internal` 头，并使用 `constantTimeEqual` 进行常量时间字符串比较。
- 日志输出使用结构化 JSON（含 `event` 字段如 `automation_dispatch_failed`、`automation_execute_ack`），便于被 Observability 采集。
- 可配置项（`APP_ORIGIN`、`SCHEDULED_TASKS_INTERNAL_TOKEN`）集中从 `Env` 接口读取并做 `.trim()` 清理，未设置时提供默认值或拒绝处理。
