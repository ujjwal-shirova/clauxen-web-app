基于 `wrangler.jsonc` 部署到 Cloudflare Workers，入口为 `src/index.ts` 中的默认导出 `fetch` 处理器，按路径分派：
- `/github/setup`、`/github`、`/github/register`：GitHub App 安装流程与用户 OAuth 连接页面。
- `/api/v1/github/*`：受速率限制（`RATE_LIMIT` Hyperdrive）的 API，包括 manifest 启动/回调、webhook 接收等。

内部按职责拆分为六个模块：`auth.ts` 处理 Supabase JWT 验证与跨域桥接 cookie；`security.ts` 提供 AES-GCM 加密封装 (`seal`/`unseal`)、HMAC webhook 校验、PKCS#1→PKCS#8 转换及 GH App JWT 签发；`database.ts` 通过 `pg` 客户端经 Hyperdrive 直连 PostgreSQL，封装事务式状态机 (`putState`/`takeState`) 与应用凭据解密；`github.ts` 统一封装 GitHub REST API 调用、OAuth token exchange 与安装态检查；`pages.ts` 返回 HTML 表单；`contracts.ts` 暴露 zod schema 供前端使用。

数据模型定义在 `schema.sql`，所有敏感字段 (`credentials_sealed`、`data_sealed`、`tokens_sealed`) 均使用 `SEAL_KEY` + context 进行 AEAD 加密后落库，表级 RLS 已启用并对 `public/anon/authenticated` 撤销权限，确保 worker 是唯一能明文访问的通道。
