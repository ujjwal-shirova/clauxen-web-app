- 所有敏感数据（GitHub PEM/secret、OAuth tokens、flow state）通过 `security.ts` 的 `seal`/`unseal` 以 `SEAL_KEY` + 上下文字符串进行 AEAD 加密后再落库，避免明文凭据进入数据库。
- 对外 HTTP 错误统一通过自定义 `HttpError(status, message)` 抛出，路由层捕获后映射为 `Response.json({ data })` 或 `Response(null, { status, headers })`。
- 外部调用 GitHub API 时统一设置 `Accept: application/vnd.github+json`、`X-GitHub-Api-Version: 2026-03-10`、`User-Agent: Clauxen-Agent`，并通过 `AbortSignal.timeout(20000)` 控制超时。
- 跨域 POST 请求在路由入口处调用 `sameOrigin(request, env)` 校验 `origin` 与 `sec-fetch-site`，防止 CSRF 类攻击。
- 一次性流式状态（registration/oauth/launch）通过 `putState`/`takeState` 写入 `private.github_agent_states`，并以 SHA-256 hash 作为主键、10 分钟 TTL 自动过期，采用 delete-returning 语义保证单次消费。
