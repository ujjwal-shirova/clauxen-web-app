- 对外部服务（Razorpay、Supabase）的请求统一通过 `index.ts` 内的封装函数发起，并在缺少环境密钥时返回明确的 503 错误响应。
- 内部接口鉴权采用双重方式：`Authorization: Bearer <BILLING_INTERNAL_TOKEN>` 或 `x-clauxen-billing` 自定义头，并通过 `timingSafeEqual` 进行常量时间比较。
- 发票金额统一以 paise（INR 最小单位）整数在类型层传递，仅在 UI 展示层通过 `Intl.NumberFormat` 格式化货币。
- PDF 文本排版使用 `StandardFonts.Helvetica` 与固定 A4 尺寸，颜色通过 `rgb(r,g,b)` 三元组常量定义，保持视觉一致性。
- 邮件发送通过 Cloudflare Email Workers binding 的 `EMAIL.send` 接口，并以 `kind` 字段区分不同模板（`invoice_paid`、`billing_address_saved/updated`、`gift_*`）。
