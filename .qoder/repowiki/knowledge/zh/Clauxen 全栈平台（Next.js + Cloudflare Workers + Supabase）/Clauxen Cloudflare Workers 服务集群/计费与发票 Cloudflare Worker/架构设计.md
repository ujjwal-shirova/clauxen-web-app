单入口 Cloudflare Worker（`src/index.ts`），按路由前缀分发到三类职责：
- `/v1/razorpay/*`：对 Razorpay REST 进行代理封装（订单、UPI QR、S2S token charge、OTP、customer、tokens、webhook 签名校验 `verify-signature`），统一鉴权头构造并透传响应。
- `/v1/invoices/*`：`generate` 调用 `invoice-pdf.ts` 用 pdf-lib 在服务端渲染 A4 PDF；`fulfill` 串联 R2 写入 + Razorpay Documents 上传 + 邮件发送，构成单调用事务。
- `/v1/email/send`：通过 Cloudflare Email Workers binding 发送账单通知。

模块内部按文件分层：`types.ts` 集中定义 `InvoiceGenerateRequest` / `InvoiceFulfillRequest` 等 DTO；`invoice-pdf.ts` 负责 PDF 布局与品牌元素（logo 以 base64 注入）；`email.ts` 提供多种邮件模板（发票已付、地址变更、礼物）；`razorpay-invoice-upload.ts` 处理 Razorpay Documents 上传。

依赖方向单向：index → invoice-pdf / email / razorpay-invoice-upload → types。外部依赖为 R2 bucket（`INVOICES`）、Supabase Auth（用户 JWT 校验）、Razorpay API、Cloudflare Email Workers，均通过 `wrangler.toml` 的 `[vars]`、`[r2_buckets]`、`[[send_email]]` 绑定注入，不直接硬编码密钥。
