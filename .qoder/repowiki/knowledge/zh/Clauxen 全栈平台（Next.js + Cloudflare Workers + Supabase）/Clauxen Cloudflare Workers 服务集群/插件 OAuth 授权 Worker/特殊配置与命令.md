部署前需在 Wrangler 中注入 secrets 与 KV 命名空间：`wrangler secret put SUPABASE_URL / SERVICE_ROLE_KEY / INTERNAL_TOKEN / TOKEN_SEAL_KEY`，以及创建两个 KV namespace（`OAUTH_STATE`、`OAUTH_CLIENTS`）并把 id 填入 `wrangler.toml`；`TOKEN_SEAL_KEY` 必须与 Next.js 应用的 `PAYMENT_METHOD_ENCRYPTION_KEY` 一致。本地开发用 `npm run dev`（`wrangler dev`），生产发布用 `npm run deploy`。
