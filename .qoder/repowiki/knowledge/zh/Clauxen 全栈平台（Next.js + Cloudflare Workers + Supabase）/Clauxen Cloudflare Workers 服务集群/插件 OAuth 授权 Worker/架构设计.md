模块以 `src/index.ts` 为唯一入口，按职责拆分为四个文件：
- `index.ts`：路由分发层，声明 `Env` 类型（KV、Supabase、内部 Token、加密密钥等），实现 `/v0/oauth/start`、`/v0/oauth/callback`、`/v0/oauth/refresh`、`/.well-known/oauth-client`、`/v0/health` 五个端点，并负责请求鉴权、URL 构建、重定向安全校验与 AES-256-GCM 加密封装。
- `oauth.ts`：纯协议实现层，遵循 Model Context Protocol Authorization Specification（MCP OAuth 2.1），依次执行 RFC 9728 受保护资源元数据发现 → RFC 8414 授权服务器发现 → CIMD/RFC 7591 动态客户端注册 → PKCE+S256 + RFC 8707 resource 参数 → 令牌交换；所有外部 HTTP 调用均带 8s 超时。
- `supabase.ts`：数据库访问层，仅通过 service-role key 调用 Supabase 的 `plugin_oauth_*` security-definer RPC，禁止将原始 token 返回给浏览器，只暴露 `completeConnection` / `rotateTokens` / `readRefreshPayload` 三个函数。
- `pages.ts`：无框架 HTML 模板生成器，输出轻量状态页与错误页。
依赖方向单向：`index.ts` → (`oauth.ts`, `supabase.ts`, `pages.ts`)；外部 KV 命名空间 `OAUTH_STATE`（待办授权状态，TTL 900s）与 `OAUTH_CLIENTS`（CIMD/注册结果缓存，TTL 86400s）由 `wrangler.toml` 配置。令牌使用共享库 `../../../src/shared/lib/plugin-token-seal` 基于 `TOKEN_SEAL_KEY` 进行对称加密后落盘，与 Next.js 应用共用同一密钥。
