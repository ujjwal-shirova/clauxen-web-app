- 对外响应统一通过 `json()` / `errorJson()` 助手构造，附带 `cache-control: no-store` 头，避免敏感中间件缓存。
- 内部调用接口通过 `x-clauxen-internal-token` 头部与 `env.INTERNAL_TOKEN` 比对来校验，非内部请求直接返回 401。
- 用户可控的重定向目标经 `safeReturnUrl()` 白名单校验，仅允许 `APP_ORIGIN` 列表中的 origin，非法值回退到 `baseOrigin(APP_ORIGIN)/plugins`。
- 敏感凭据（access_token / refresh_token）在写入 Supabase 前一律通过 `sealSecret` 进行 AES-256-GCM 密封，读取时对称解封，Worker 不存储明文。
- HTTP 出站调用统一使用 `AbortSignal.timeout(DISCOVERY_TIMEOUT_MS)` 限制外部依赖延迟，失败路径抛出语义化 Error 子类（`McpOAuthError`、`SupabaseError`）。
