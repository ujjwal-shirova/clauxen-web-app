- 所有对外响应统一通过 `json(data, status, extra?)` 辅助函数构造，附带隐私头集合 `PRIVACY_HEADERS`（robots-tag、cache-control、referrer-policy、nosniff）。
- 内部接口通过比较 `x-clauxen-internal` 请求头与 `SHARE_WORKER_INTERNAL_TOKEN` 环境变量进行授权，使用 `crypto.subtle.timingSafeEqual` 避免时序攻击。
- KV 键采用前缀约定 `share:{sha256Hex(tokenHash)}`，tokenHash 以十六进制正则 `/^[a-f0-9]{64}$/` 校验后再落盘。
- 跨域允许的主机列表来自 `APP_ORIGIN` 环境变量，支持精确匹配与 `https://*.suffix` 通配规则，未匹配时仅返回 `vary: origin`。
