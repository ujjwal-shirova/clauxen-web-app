单入口 Cloudflare Worker（`src/index.ts`），暴露三类能力：
- 内部 API：`publish`/`revoke` 仅接受带 `x-clauxen-internal` 头的请求，使用 `crypto.subtle.timingSafeEqual` 对比 `SHARE_WORKER_INTERNAL_TOKEN` 完成授权后写入/删除 `SHARE_KV` 中 `share:{sha256(tokenHash)}` 键。
- 公开 API：读取快照、校验 Turnstile token、校验来源主机，并返回 JSON 响应。
- 共享库依赖：从上层 `src/shared/lib/share-public` 导入类型与常量（`SharedChatSnapshot`、`parseShareSnapshot`、`isAllowedShareHostname`、`SHARE_ROBOTS_TAG`、`SHARE_TURNSTILE_ACTION`、`TURNSTILE_TEST_SECRET`）。
配置由 `wrangler.toml` 声明 KV binding、`APP_ORIGIN` / `ALLOW_TEST_TURNSTILE` 环境变量及 Secrets；部署名 `clauxen-share-gate`，启用 observability 且 head_sampling_rate=0.05。
