- 对外部 HTTP 请求统一通过 `appFetch(env, url, init)` 包装，优先走 Cloudflare Service Binding `env.APP.fetch`，否则回退到全局 `fetch`。
- 敏感令牌通过 `x-clauxen-internal` 请求头传递，并在 `/v1/continue` 入口使用 SHA-256 哈希后逐位异或比较，避免 timing attack。
- 所有出站请求携带固定 `user-agent: clauxen-generations-watchdog/1.0`，并通过 `AbortSignal.timeout(15_000)` 强制超时。
- 错误路径统一通过 `console.error(JSON.stringify({ event: ..., ... }))` 结构化日志输出，而非普通字符串。
