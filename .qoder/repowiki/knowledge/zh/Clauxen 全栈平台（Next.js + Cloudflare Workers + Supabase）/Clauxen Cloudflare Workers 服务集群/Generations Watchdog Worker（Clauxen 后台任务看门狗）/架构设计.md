单一入口 `src/index.ts` 同时实现三类 Cloudflare Worker 入口：
- `fetch`：处理 `/health`、`/v1/continue`（POST，需 `x-clauxen-internal` 令牌校验）两个 HTTP 端点；前者返回健康状态，后者透传上游 `CONTINUATION_ORIGIN` 的 `/api/v1/internal/generations/continue` 响应。
- `scheduled`：由 `[triggers].crons = "* * * * *"` 每分钟触发，调用 `pokeWatchdog` 去探活 `APP_ORIGIN` 下的 `/api/v1/internal/generations/watchdog?source=cloudflare`。
- 通过 `Env.APP`（Cloudflare Service Binding `Fetcher`）或回退到全局 `fetch` 统一访问上游，默认走 `https://www.clauxen.com`，Vercel 直连走 `CONTINUATION_ORIGIN`。

依赖方向单向向外：本 worker 仅作为客户端调用外部 API，不持有业务状态；配置全部来自 `wrangler.toml` 的 `[vars]` 与 `wrangler secret put` 注入的 secrets（`GENERATIONS_INTERNAL_TOKEN`、`VERCEL_AUTOMATION_BYPASS_SECRET`、`APP_ORIGIN`、`CONTINUATION_ORIGIN`）。重试逻辑封装在 `pokeWatchdog` 中，最多 3 次、指数退避 250ms，非 5xx 且非 429 即视为成功。
