每个子目录是一个独立的 wrangler Worker（含自己的 package.json、tsconfig、wrangler.toml），彼此不共享代码，而是通过 HTTP API 与外部系统交互：
- 认证域：auth-email、native-auth、oauth-broker 共同支撑 OAuth/OTP/魔法链接流程；supabase-proxy 将 /auth、/rest、/storage、/realtime、/functions、/graphql/v1 安全转发到 Supabase。
- 数据与存储域：r2-gateway、cdn 提供 R2 直传与插件图标静态分发；github-agent、chat-coord、chat-history、share-gate、plugin-oauth 各自维护或代理 Supabase/Postgres/KV 资源。
- 业务编排域：billing 聚合 Razorpay/R2/PDF/邮件；generations-watchdog、scheduled-tasks 作为定时看门狗轮询后端与 Queue。
所有 Worker 通过环境变量注入 Secrets（由 wrangler.toml / .dev.vars 管理），并通过 wrangler deploy 分别部署到各自的 cloudflare 项目。
