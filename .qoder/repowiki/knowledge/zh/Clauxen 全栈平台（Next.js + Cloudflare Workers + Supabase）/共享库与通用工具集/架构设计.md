模块以 `src/shared/` 为根，按职责划分为三个子目录：
- `lib/api/`：基于 `client.ts` 中统一的 `sessionFetch`/`apiFetch`（含 60s 超时、401 自动刷新、安全挑战重试、JSON 载荷解析）派生各业务 REST 客户端文件（auth、chats、projects、billing、workspaces 等），对外仅暴露方法签名。
- `lib/`：扁平的纯函数库，覆盖聊天（chat-*）、模型编目、流式文本、MCP 插件、结账（razorpay/*）、设置归一化、键盘快捷键、语音/视频帧等；同时包含少量 React 组件（如 `highlight-code.tsx`、`smooth-streaming-text.tsx`）供 UI 层复用。
- `utils/supabase/`：封装 Supabase SSR 客户端实例化、环境变量读取与服务端中间件；`types/database.types.ts` 由 Supabase 生成，作为整个 shared 层的数据库类型契约。
依赖方向单向：UI 层 → shared/lib → shared/utils；shared 内部各文件之间通过命名导出互相引用，无全局副作用单例（除 `createClient` 的单例缓存外）。
