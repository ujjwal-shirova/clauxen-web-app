该模块是 `.agents/skills/` 下的纯文档型技能注册目录，每个子目录代表一个独立 skill：
- `clauxen-cli/SKILL.md`：通过 YAML front-matter（`name`、`description`、`metadata.version`、`metadata.platform`）声明 macOS 平台上的 CLI 工具集（gh/glab/wrangler/supabase/clauxen-cli），并规定 Keychain 凭据注入、token 拦截与审计等安全约束。
- `frontend-design/SKILL.md`：附带 `LICENSE.txt`，以角色化指令（"design lead at a design studio"）给出前端视觉设计流程与反模板清单。
两个 skill 均遵循同一约定：用 Markdown + YAML front-matter 描述能力边界，由上层 agent 框架按需加载；本模块不含任何可执行代码，仅作为人类与 AI 之间对能力的契约。
