模块由两个并列子目录构成：
- `src/ui/settings/`：设置页面的完整 UI 层。`settings-ui.tsx` 提供可复用的布局原语（`SettingsPage`、`SettingsSection`、`SettingsRow`、`SettingsToggleRow`、`SettingsPanelHeaderWithHelp` 等），供所有具体设置页复用；`settings-nav-sidebar.tsx` 渲染左侧分组导航，支持搜索过滤和移动端抽屉变体；`constants.ts` 集中声明可见 tab、分组、图标、描述与搜索关键词，是导航与业务页之间的契约。
- 每个设置分类以独立文件组织（如 `general-settings.tsx`、`security-settings.tsx`、`billing-settings.tsx`、`mfa-setup-dialogs.tsx` 等），并通过 `@/lib/app-preferences`、`@/lib/keyboard-shortcuts-defaults` 等上层 lib 读写偏好数据，不直接耦合 API。
- `src/ui/shell/sidebar.tsx` 仅为重导出，将 Shell 侧边栏指向 `@/components/sidebar`，本身不参与设置逻辑。
依赖方向单向：具体设置页 → `settings-ui` 原语 + `constants`；导航侧边栏 → `constants`；shell 侧边栏无内部依赖。
