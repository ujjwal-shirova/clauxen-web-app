- 每个设置分类以独立 `.tsx` 文件暴露默认或具名组件，通过导入 `settings-ui` 中的 `SettingsSection` / `SettingsRow` / `SettingsToggleRow` 等原语拼装内容。
- 导航项在 `constants.ts` 中以 `settingsNav` 数组声明（含 name/icon），并通过 `settingsNavByName`、`settingsNavGroups`、`settingsItemLabel` 派生菜单与分组，新增分类需在此集中注册。
- 对已废弃的旧 tab 名称通过 `resolveVisibleTab` 映射到当前可见 tab，保证深度链接向后兼容。
- 设置行使用 `SettingsRow` 包裹 label/description/control，并配合 `aria-labelledby` / `aria-describedby` 与 `role="group"` 保持无障碍语义。
- 对话框类交互（添加支付方式、裁剪头像、MFA 设置、管理计划）统一以独立的 `*-dialog.tsx` 文件封装，基于 Radix DialogPrimitive 构建。
