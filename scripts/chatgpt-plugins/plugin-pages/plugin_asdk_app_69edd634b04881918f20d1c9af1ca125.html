About Tripuck

Tripuck is a flight meta-search and trip-planning service. This connector lets you search live flight prices, explore a route's cheapest days of the month, browse popular destinations from any origin city, and open full segment / baggage details for any result — all without leaving the chat. Tripuck's signature feature is **Meeting Point**: given 2-5 travelers flying from different cities, it computes the cheapest and fairest common destination, along with a per-person price breakdown and a fairness score. It's ideal for coordinating trips where the group is spread across several countries. Every result deep-links back to tripuck.com for booking review and checkout. The connector itself is read-only — it does not book, charge, modify accounts, or hold any user payment information. Supported user languages: Turkish, English, Arabic, Azerbaijani, German, Georgian, and Uzbek. The tool infers the user's language from the conversation and returns responses in that language, including right-to- left layout for Arabic.
