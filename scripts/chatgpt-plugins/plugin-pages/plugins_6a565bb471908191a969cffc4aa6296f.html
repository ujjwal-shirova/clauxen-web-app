About Career Centre

Career Centre has no separate subscription: it uses the user's ChatGPT plan and sends nothing to a publisher-operated CV backend. Upload one or several CVs for a candid first review, selective role recommendations with exact links and salary context, and polished Word application packs. It automatically prepares a portable Career Passport, keeps submission manual, adapts to the candidate's market, and proactively offers to create a daily or weekday Scheduled search from the same Work task after the first manual run. A reference Word format is supported only when the user explicitly asks for it.
