About Slop Curator

Slop Curator is a skills-only Plugin built as a connected set of full specialist Skills. It audits named slop patterns, detects excessive short-line and staccato formatting, preserves an existing writer voice, reconstructs natural spoken prose, handles Egyptian Arabic and Arabic-English code-switching, enforces portable or strict house-style rules, builds truthful commercial copy and practical marketing playbooks, reviews presentation and visual-content direction for AI-design clichés and RTL risks, applies targeted repairs, and runs a final quality gate. The router loads only the Skills and policy profiles needed for the request so personal house rules do not become universal bans. No external server or authentication is required.
