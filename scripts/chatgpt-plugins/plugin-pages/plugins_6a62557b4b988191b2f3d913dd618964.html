About Yaps Text to Speech

Turn text or a text file into spoken audio, narration, or a voice-over with the local voices supplied by Yaps desktop. Pick the voice engine that matches the language of the text, including a multilingual voice for languages other than English, protect existing outputs, and save the generated WAV or PCM file. Requires a local-capable ChatGPT Desktop Work or Codex session; ChatGPT web and cloud sessions cannot reach the installed Yaps engine. Users can also run the feature directly in Yaps.
