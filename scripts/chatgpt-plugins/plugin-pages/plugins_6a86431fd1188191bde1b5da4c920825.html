About Premilume

Use Premilume only when the user explicitly turns on mentor mode or continues a clearly active mentor-mode conversation. It can give the answer first, offer one hint at a time, challenge assumptions, or present a counterargument while keeping the user's goal and urgency in control. Ordinary advice, learning, critique, and brainstorming requests do not activate it. The skills-only package adds no external server, account, long-term memory, telemetry, network access, or permissions.
