About Content Brief Extractor

Content Brief Extractor extracts structured content brief fields from content request text. It returns topic, target audience, channel, deadline, missing fields, and errors. It does not write content, create marketing strategy, choose channels, schedule posts, publish content, or call external systems. The app is stateless, read-only, and only processes the submitted text for the current request.
