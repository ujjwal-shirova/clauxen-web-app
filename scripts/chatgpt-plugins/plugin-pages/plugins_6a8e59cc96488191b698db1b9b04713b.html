About Completion Receipt

Use Completion Receipt when completed agent work or a release check needs a full record someone else can review. Using the supplied approved command and selected paths, it captures what ran, the result, selected file hashes, Git state, and later drift on those paths. It records observed evidence; it does not prove correctness, security, identity, authorization, or sandboxing.
