About Fullstack Dev Kit

Takes a ticket (Jira / Linear / GitHub Issues / Azure) from plan-approval through implementation, adaptive tests/coverage, security and accessibility review, to an opened pull request. Stack-agnostic. The issue tracker and PR host are configured per repo; connect the matching MCP (e.g. Atlassian for Jira, Linear) to let the kit read tickets.
