About Agent Ready

Agent Ready checks how readable any website is to AI agents, assistants, and crawlers. Give it a URL and it scans the site against the Vercel Agent Readability Spec, the llms.txt standard, and emerging agent protocols (MCP server cards, A2A agent cards, agents.json), then renders an interactive score card: a 0–100 agent-readability score, an llms.txt score, and a per-check breakdown grouped by site, page, llms.txt, and protocol - each failing check paired with a plain-English fix. Use it to find out why AI tools can't read your content, validate your llms.txt and AGENTS.md, confirm your structured data and Markdown mirrors, and re-scan any time to check that your fixes landed. Each result links to a full, shareable report on agent-ready.dev. Free to use, no account required.
