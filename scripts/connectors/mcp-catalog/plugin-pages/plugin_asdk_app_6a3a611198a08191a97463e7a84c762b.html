About Klardaten DATEV-Connector

Klardaten DATEV-Connector helps authorized users retrieve read-only DATEV accounting, payroll, document management, order management, and master data through ChatGPT. For tax advisors, accountants, finance teams, and business owners using DATEV, it supports guided discovery of available resources, scoped list and detail lookups, financial reporting queries, DMS document lookup with short-lived signed download links, order inspection, payroll snapshots, and master-data access for clients, contacts, and organizational records. Access is limited to DATEV data the authenticated user is authorized to view.
