About AI Passport

AI Passport is your own memory layer for the AI apps you use. Save a preference, decision, project, or note once and recall it in any connected assistant, so you stop repeating yourself. You stay in control: normal saves arrive as proposals you approve, and each app gets an exact, revocable pass to a category you choose, so no assistant gets blanket access to everything.
