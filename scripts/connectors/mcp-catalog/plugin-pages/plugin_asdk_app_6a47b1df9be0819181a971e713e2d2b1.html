About WP Agent

WordPress sites managed entirely from ChatGPT — connect your site once and ChatGPT can write, edit, publish, schedule, and maintain it end to end. WP Agent is keyless: you don't bring an AI API key. ChatGPT authors the content, image prompts, and SEO; WP Agent executes them on your WordPress site through purpose-built tools. Create, edit, schedule, and publish posts and pages, update existing content, and manage revisions. Handle the full media library: upload images, generate AI hero images or pull free stock photos, and set featured images sized for WordPress. Run complete SEO workflows — titles, meta descriptions, focus keywords, and per-post SEO analysis. Manage categories, tags, menus, comments, authors, site settings, custom CSS, and plugins — all from ChatGPT. Safe by design: destructive actions are confirm-gated, publishing is explicit, and every tool call is audited. Works with any self-hosted WordPress site: connect with a one-time approval link in wp-admin, using a standard, revocable application password. The optional WP Agent Connector plugin adds SEO meta support (Yoast, Rank Math, AIOSEO) and compatibility with restrictive hosts.
