About Zeck

This connector will allow Codex or ChatGPT to read information stored in your Zeck companies. It authorizes using your existing Zeck user account to only be able to read information you have permission to view. After connected, it can read a user's companies, the list of Zecks in each company, and the contents of published Zecks. This allows collaboration with Codex or ChatGPT for securely permissioned Zeck materials.
