About ScalperIntel AI

ScalperIntel AI answers questions about ScalperIntel's indicators and lets verified customers manage their own licenses without leaving the chat. Connecting takes one step: enter an email and the 6-digit code sent to it. With any email it answers from ScalperIntel's official product knowledge base — what an indicator detects and plots, what each setting does when you change it, installation and setup on NinjaTrader 8, chart and bar-type compatibility, pricing and license types, and which indicator suits a given style of trading. Answers are grounded in that knowledge base and cited rather than improvised. Sign in with the email used to purchase and it also acts on that account: list licenses and their status, diagnose a license problem against the real license state rather than a guess, submit a new machine ID, switch between Named User and Machine ID activation, and log an issue for the support team with a reference number. Scope is enforced in code, not by instruction. It gives no trading advice and makes no performance or profit claims; it answers about the software only. The signed-in email is read from the verified session and never from text typed into a prompt, so the license tools can only ever act on the account that signed in.
